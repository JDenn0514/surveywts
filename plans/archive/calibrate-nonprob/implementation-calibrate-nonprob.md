# implementation-calibrate-nonprob.md

## Summary

- `calibrate_to_survey()` and `calibrate_to_estimate()` now accept
  `survey_nonprob` objects with replicate weights as valid inputs in addition
  to `survey_replicate` objects.
- The output class is determined by the class of the primary (or sole) design
  input: `survey_nonprob` in → `survey_nonprob` out; `survey_replicate` in →
  `survey_replicate` out.
- Three new error classes were added for the case where a `survey_nonprob`
  input is provided but has no replicate weights populated:
  `surveywts_error_primary_no_repweights`,
  `surveywts_error_control_no_repweights`,
  `surveywts_error_design_no_repweights`.
- Existing `_not_replicate` error messages were updated to acknowledge
  `survey_nonprob` as a second accepted class.
- Two new test helpers were added to `helper-test-data.R`:
  `make_nonprob_replicate_design()` (nonprob with bootstrap repweights) and
  `make_nonprob_no_repweights()` (nonprob without repweights, for error paths).

## Notes for Tester

- Tests in sections 12–13 and 15–17 call `make_nonprob_replicate_design()`,
  which runs `ipw()` + `create_bootstrap_weights()` with 50 replicates. This
  makes these tests ~10–15s slower than the existing sample-calibration suite.
  All are guarded with `skip_if_not_installed("svrep")`.
- The 671 warnings observed during test runs are from `ipw()`'s
  `adjust_reference` behavior in the helper function setup — they are expected
