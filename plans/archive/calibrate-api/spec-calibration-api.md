# Spec — calibration-api

**Status**: SPEC_REVIEWED
**Target version**: 0.6.0.9000
**PR range**: PR 1–2

---

## Document Purpose

This spec is the behavioral contract for redesigning the calibration function
family. It governs what the builder implements. Every exported function, every
argument, every error class, and every edge case is specified here. The builder
reads only this document.

The three existing calibration functions (`calibrate()`, `rake()`,
`poststratify()`) are **deleted** and replaced by `calibrate_greg()`,
`calibrate_rake()`, `calibrate_poststrat()`, and a new thin-dispatcher
`calibrate()`. The new API uses a harmonized `targets` argument across all
three substantive functions.

|------|--------|
| Changes to calibration engine internals | No behavioral change; only public API changes |

| Input class | Behavior |
|-------------|----------|

| Any other class | Error: `surveywts_error_unsupported_class` |

## III. `calibrate_greg()`

### Signature

```r
calibrate_greg(
  data,
  targets,
  weights          = NULL,
  wt_name          = "wts",
  model            = c("linear", "logit"),
  type             = c("prop", "count"),
  control          = list(maxit = 50, epsilon = 1e-7),
  reference_design = NULL
)
```

Argument order follows `code-style.md`: `data` (required, object) → `targets`
(required) → optional NSE (`weights`) → optional scalars.

### Arguments

| Arg | Type | Default | Description |
|-----|------|---------|-------------|
| `data` | `data.frame`, `weighted_df`, `survey_taylor`, or `survey_nonprob` | required | Input data. `survey_replicate` → error. Any other class → error. |
| `targets` | named list | required | Population marginal targets. Named list of named numeric vectors (Format A) or a long data frame with columns `variable`, `level`, `target` (Format B). Format B is auto-converted to Format A via `.parse_margins()` before use. Names must match column names in `data`. For `type = "prop"`: each element must sum to 1.0 within 1e-6. For `type = "count"`: all values must be strictly positive, and all marginal vectors must sum to the same population total N within 1e-3 (cross-marginal consistency). |
| `weights` | tidy-select bare name | `NULL` | Weight column name. `NULL` → auto-detected from `weighted_df` attribute or survey object `@variables$weights`. For plain `data.frame` with `weights = NULL`, uniform starting weights (1/n each) are created and the output column is named `wt_name`. |
| `wt_name` | `character(1)` | `"wts"` | Name of the output weight column in the returned `weighted_df`. Ignored when `data` is a survey object. |
| `model` | `character(1)` | `"linear"` | GREG calibration model. `"linear"`: one-step exact GREG (may produce negative weights). `"logit"`: bounded iterative calibration (always positive). |
| `type` | `character(1)` | `"prop"` | Interpretation of `targets` values. `"prop"`: proportions summing to 1.0. `"count"`: population counts. |
| `control` | named list | `list(maxit = 50, epsilon = 1e-7)` | Convergence parameters. Merged with defaults; omitted keys retain defaults. `maxit`: maximum iterations. `epsilon`: convergence threshold. Unrecognized keys trigger `surveywts_warning_control_param_ignored` (one warning per key). |
| `reference_design` | `survey_taylor` or `NULL` | `NULL` | The probability survey from which `targets` were estimated. When non-`NULL`, stored in the history entry and `targets_from_reference = TRUE`. Must be `survey_taylor` or `NULL`; any other non-`NULL` class → error. |

### Relationship to old `calibrate()`

`calibrate_greg()` is a direct rename of old `calibrate()` with one API change:
the `variables` (tidy-select) + `population` (named list) arguments are
replaced by a single `targets` argument that accepts both the named list format
(old `population`) and Format B long data frame (already supported by `rake()`).
The tidy-select `variables` argument is removed because `targets` names already
specify which columns to calibrate on.

### Returns

- `data.frame` or `weighted_df` input → `weighted_df` with calibrated weights
  in the `wt_name` column (default `"wts"`).
- `survey_taylor` or `survey_nonprob` input → same class as input (class
  preserved); only the weight column values and `@metadata@weighting_history`
  are updated.

A history entry with `operation = "calibrate_greg"` is appended to
`weighting_history`. The history entry `parameters` field includes:
`variables` (character vector of target variable names), `targets` (stored as
Format A named list), `model`, `type`, `control`, `targets_from_reference`,
`reference_design`.

### Errors

| Class | Trigger condition |
|-------|-------------------|
| `surveywts_error_unsupported_class` | `data` is not a supported class |
| `surveywts_error_replicate_not_supported` | `data` is `survey_replicate` |
| `surveywts_error_empty_data` | `nrow(data) == 0` |
| `surveywts_error_weights_not_found` | Named weight column missing from `data` |
| `surveywts_error_weights_not_numeric` | Weight column is not numeric |
| `surveywts_error_weights_nonpositive` | Weight column has values ≤ 0 |
| `surveywts_error_weights_na` | Weight column has `NA` |
| `surveywts_error_wt_name_not_scalar` | `wt_name` is not `character(1)` |
| `surveywts_error_wt_name_empty` | `wt_name` is `NA` or `""` |
| `surveywts_error_reference_design_not_taylor` | `reference_design` is non-`NULL` and not `survey_taylor` |
| `surveywts_error_margins_format_invalid` | `targets` is not a named list or valid Format B data frame (error class reused from rake family; same structural condition) |
| `surveywts_error_targets_variable_not_found` | A `targets` name not found in `data` |
| `surveywts_error_variable_not_categorical` | A calibration variable is numeric or integer |
| `surveywts_error_variable_has_na` | A calibration variable has `NA` values |
| `surveywts_error_population_level_missing` | A data level absent from `targets` |
| `surveywts_error_population_level_extra` | A `targets` level absent from `data` |
| `surveywts_error_population_totals_invalid` | `type = "prop"` proportions don't sum to 1, or `type = "count"` target ≤ 0, or `type = "count"` marginal sums are inconsistent across variables (difference > 1e-3) |
| `surveywts_error_calibration_not_converged` | Max iterations reached without convergence |

### Warnings

| Class | Trigger condition |
|-------|-------------------|
| `surveywts_warning_negative_calibrated_weights` | `model = "linear"` produced one or more negative calibrated weights |
| `surveywts_warning_control_param_ignored` | A `control` key is not one of `maxit` or `epsilon` (one warning per unrecognized key) |

### Edge cases

| Case | Specified behavior |
|------|-------------------|
| 0-row `data` | Error: `surveywts_error_empty_data` |
| 1-row `data` | Accepted; calibration proceeds; result is exact for the single matching cell |
| All-NA calibration variable | Error: `surveywts_error_variable_has_na` (caught by variable NA check) |
| Single-level calibration variable (all rows same value) | Calibration proceeds normally; the single-level target multiplier adjusts all weights uniformly |
| Zero-weight rows | Error: `surveywts_error_weights_nonpositive` (caught by weight validation) |
| `targets` is a Format B long data frame | Auto-converted to Format A via `.parse_margins()` before all downstream processing |
| `weights = NULL` on plain `data.frame` | Uniform starting weights 1/n; output column named by `wt_name` |
| `model = "logit"` does not converge | Error: `surveywts_error_calibration_not_converged` |
| `model = "linear"` produces negative weights | Warning: `surveywts_warning_negative_calibrated_weights`; negative weights are retained in output |
| `type = "count"` with inconsistent marginal sums (>1e-3 apart) | Error: `surveywts_error_population_totals_invalid` with message identifying which marginals are inconsistent and their sums |
| `control` contains unrecognized key (e.g., `control = list(pval = 0.05)`) | Warning: `surveywts_warning_control_param_ignored` per unrecognized key; unrecognized keys are dropped |

## IV. `calibrate_rake()`

### Signature

```r
calibrate_rake(
  data,
  targets,
  weights          = NULL,
  wt_name          = "wts",
  type             = c("prop", "count"),
  algorithm        = c("anesrake", "survey"),
  cap              = NULL,
  control          = list(),
  reference_design = NULL
)
```

### Arguments

| Arg | Type | Default | Description |
|-----|------|---------|-------------|
| `data` | `data.frame`, `weighted_df`, `survey_taylor`, or `survey_nonprob` | required | Input data. `survey_replicate` → error. Any other class → error. |
| `targets` | named list or data frame | required | Marginal population targets. Accepts the same two formats as `calibrate_greg()`: Format A (named list of named numeric vectors) or Format B (long data frame with `variable`, `level`, `target` columns). Auto-converted to Format A before use. For `type = "count"`: all marginal vectors must sum to the same population total N within 1e-3 (cross-marginal consistency). |
| `weights` | tidy-select bare name | `NULL` | Weight column name. Same auto-detection and uniform-weight creation behavior as `calibrate_greg()`. |
| `wt_name` | `character(1)` | `"wts"` | Output weight column name; ignored for survey objects. |
| `type` | `character(1)` | `"prop"` | `"prop"`: targets are proportions summing to 1.0. `"count"`: targets are counts. |
| `algorithm` | `character(1)` | `"anesrake"` | Raking algorithm. `"anesrake"`: chi-square variable selection with improvement-based convergence. `"survey"`: fixed-order IPF with epsilon-based convergence. |
| `cap` | `numeric(1)` or `NULL` | `NULL` | Weight ratio cap `w / mean(w)`. Applied after each per-margin step. `NULL` = no cap. Not compatible with `algorithm = "survey"` (→ error). |
| `control` | named list | `list()` | Algorithm parameters. Merged with algorithm-specific defaults. `"anesrake"` defaults: `maxit = 1000L`, `improvement = 0.01`, `pval = 0.05`, `min_cell_n = 0L`, `variable_select = "total"`. `"survey"` defaults: `maxit = 100L`, `epsilon = 1e-7`. Keys for the wrong algorithm trigger `surveywts_warning_control_param_ignored` per parameter. |
| `reference_design` | `survey_taylor` or `NULL` | `NULL` | Same as `calibrate_greg()`. |

### Relationship to old `rake()`

`calibrate_rake()` is a direct rename of old `rake()` with one API change:
the `margins` argument is renamed to `targets`. All other arguments, formats,
defaults, algorithm behavior, and internal logic are identical to `rake()`.

### Returns

Same class-preservation behavior as `calibrate_greg()`. History entry has
`operation = "calibrate_rake"`. Parameters field: `variables`, `targets`
(stored as Format A), `type`, `algorithm`, `cap`, `control`,
`targets_from_reference`, `reference_design`.

### Errors

| Class | Trigger condition |
|-------|-------------------|
| `surveywts_error_unsupported_class` | `data` is not a supported class |
| `surveywts_error_replicate_not_supported` | `data` is `survey_replicate` |
| `surveywts_error_empty_data` | `nrow(data) == 0` |
| `surveywts_error_weights_not_found` | Named weight column missing |
| `surveywts_error_weights_not_numeric` | Weight column not numeric |
| `surveywts_error_weights_nonpositive` | Weight column has values ≤ 0 |
| `surveywts_error_weights_na` | Weight column has `NA` |
| `surveywts_error_wt_name_not_scalar` | `wt_name` is not `character(1)` |
| `surveywts_error_wt_name_empty` | `wt_name` is `NA` or `""` |
| `surveywts_error_reference_design_not_taylor` | `reference_design` is non-`NULL` and not `survey_taylor` |
| `surveywts_error_margins_format_invalid` | `targets` is not a named list or valid Format B data frame |
| `surveywts_error_targets_variable_not_found` | A `targets` variable name not found in `data` |
| `surveywts_error_variable_not_categorical` | A raking variable is numeric or integer |
| `surveywts_error_variable_has_na` | A raking variable has `NA` values |
| `surveywts_error_population_level_missing` | A data level absent from `targets` |
| `surveywts_error_population_level_extra` | A `targets` level absent from `data` |
| `surveywts_error_population_totals_invalid` | `type = "prop"` proportions don't sum to 1, or `type = "count"` target ≤ 0, or `type = "count"` marginal sums are inconsistent across variables (difference > 1e-3) |
| `surveywts_error_calibration_not_converged` | Max iterations reached without convergence |
| `surveywts_error_cap_not_supported_survey` | `cap` is non-`NULL` and `algorithm = "survey"` |

### Warnings

| Class | Trigger condition |
|-------|-------------------|
| `surveywts_warning_control_param_ignored` | A `control` key is not applicable to the selected `algorithm` |

### Messages

| Class | Trigger condition |
|-------|-------------------|
| `surveywts_message_already_calibrated` | `algorithm = "anesrake"` and all variables pass chi-square threshold in sweep 1 |

### Edge cases

| Case | Specified behavior |
|------|-------------------|
| 0-row `data` | Error: `surveywts_error_empty_data` |
| `targets` Format B data frame | Auto-converted to Format A |
| `cap` non-`NULL` and `algorithm = "survey"` | Error: `surveywts_error_cap_not_supported_survey` (checked before margin parsing) |
| `control` keys for wrong algorithm | Warning per ignored key: `surveywts_warning_control_param_ignored` |
| Non-convergence in `maxit` iterations | Error: `surveywts_error_calibration_not_converged` |
| All variables already at targets (`algorithm = "anesrake"`) | Message: `surveywts_message_already_calibrated`; weights returned unchanged |
| Zero-weight rows | Error: `surveywts_error_weights_nonpositive` |
| Single-level raking variable | Raking proceeds; the single level's target multiplier adjusts all weights uniformly |
| `type = "count"` with inconsistent marginal sums (>1e-3 apart) | Error: `surveywts_error_population_totals_invalid` with message identifying which marginals are inconsistent and their sums |

## V. `calibrate_poststrat()`

### Signature

```r
calibrate_poststrat(
  data,
  targets,
  weights          = NULL,
  wt_name          = "wts",
  type             = c("prop", "count"),
  reference_design = NULL
)
```

### The `targets` argument for `calibrate_poststrat()`

**Design decision:** `calibrate_poststrat()` uses `targets` as the argument
name (consistent with `calibrate_greg()` and `calibrate_rake()`), but the
accepted format is different because poststratification matches joint cells,
not marginals.

`targets` must be a `data.frame` with:
- One column per stratification variable (column names identify which variables
  to poststratify on, replacing the old tidy-select `strata` argument).
- One column named `"target"` containing population values.
- One row per unique joint cell combination.

This is the same structure as the old `population` argument in `poststratify()`.
The column names of `targets` (excluding `"target"`) implicitly define the
stratification variables, replacing the separate `strata` tidy-select argument.
All column names except `"target"` are treated as stratification variable names
and must match column names in `data`.

The `targets` data frame format cannot be interchanged with the Format A/B
marginal formats used by `calibrate_greg()` and `calibrate_rake()`. This
structural difference is documented in the `@param targets` roxygen block.

### Arguments

| Arg | Type | Default | Description |
|-----|------|---------|-------------|
| `data` | `data.frame`, `weighted_df`, `survey_taylor`, or `survey_nonprob` | required | Input data. `survey_replicate` → error. Any other class → error. |
| `targets` | `data.frame` | required | Joint cell population targets. A data frame with one column per stratification variable (names must match `data` columns), one `"target"` column, and one row per unique cell combination. For `type = "prop"`: `target` values must sum to 1.0 within 1e-6. For `type = "count"`: all `target` values must be strictly positive. Unlike `calibrate_greg()` and `calibrate_rake()`, this argument does not accept Format A or Format B marginal-target formats. |
| `weights` | tidy-select bare name | `NULL` | Weight column name. Same behavior as `calibrate_greg()`. |
| `wt_name` | `character(1)` | `"wts"` | Output weight column name; ignored for survey objects. |
| `type` | `character(1)` | `"prop"` | `"prop"`: `target` values are proportions summing to 1.0. `"count"`: `target` values are counts. |
| `reference_design` | `survey_taylor` or `NULL` | `NULL` | The reference probability survey from which `targets` were estimated. When non-`NULL`, stored in the history entry and `targets_from_reference = TRUE`. Must be `survey_taylor` or `NULL`; any other non-`NULL` class → error. |

### Relationship to old `poststratify()`

`calibrate_poststrat()` replaces old `poststratify()` with three API changes:

1. The `strata` (tidy-select) + `population` (data frame) arguments are
   replaced by a single `targets` data frame argument. The stratification
   variables are now identified by the column names of `targets` (excluding
   `"target"`), not by a separate tidy-select expression.
2. The function is renamed from `poststratify()` to `calibrate_poststrat()`.
3. `reference_design = NULL` is added for consistency with `calibrate_greg()`
   and `calibrate_rake()`.

All other behavior — the algorithm (one-pass exact cell matching), error
conditions, edge case handling, and output class rules — is identical to
`poststratify()`.

### Returns

Same class-preservation behavior as `calibrate_greg()`. History entry has
`operation = "calibrate_poststrat"`. Parameters field: `variables` (character
vector of stratification column names, derived from `names(targets)` excluding
`"target"`), `targets` (the input data frame), `type`, `targets_from_reference`,
`reference_design`.

### Errors

| Class | Trigger condition |
|-------|-------------------|
| `surveywts_error_unsupported_class` | `data` is not a supported class |
| `surveywts_error_replicate_not_supported` | `data` is `survey_replicate` |
| `surveywts_error_empty_data` | `nrow(data) == 0` |
| `surveywts_error_weights_not_found` | Named weight column missing |
| `surveywts_error_weights_not_numeric` | Weight column not numeric |
| `surveywts_error_weights_nonpositive` | Weight column has values ≤ 0 |
| `surveywts_error_weights_na` | Weight column has `NA` |
| `surveywts_error_wt_name_not_scalar` | `wt_name` is not `character(1)` |
| `surveywts_error_wt_name_empty` | `wt_name` is `NA` or `""` |
| `surveywts_error_reference_design_not_taylor` | `reference_design` is non-`NULL` and not `survey_taylor` |
| `surveywts_error_margins_format_invalid` | `targets` is not a `data.frame` (e.g., a named list or scalar) |
| `surveywts_error_no_strata_variables` | `targets` is a data frame with no non-`"target"` columns (zero stratification variables declared) |
| `surveywts_error_targets_variable_not_found` | A non-`"target"` column name in `targets` is not a column in `data` (checked before the cell-matching join) |
| `surveywts_error_variable_has_na` | A stratification variable in `data` has `NA` values |
| `surveywts_error_population_totals_invalid` | `type = "prop"` targets don't sum to 1, or `type = "count"` target ≤ 0 |
| `surveywts_error_population_cell_duplicate` | A cell combination appears more than once in `targets` |
| `surveywts_error_population_cell_missing` | A cell in `data` has no row in `targets`, or `targets` is missing a required column |
| `surveywts_error_population_cell_not_in_data` | A `targets` row cell has no observations in `data` |
| `surveywts_error_empty_stratum` | A cell has zero weighted count (defensive; see edge cases) |

### Edge cases

| Case | Specified behavior |
|------|-------------------|
| 0-row `data` | Error: `surveywts_error_empty_data` |
| `targets` missing `"target"` column | Error: `surveywts_error_population_cell_missing` |
| `targets` has no non-`"target"` columns | Error: `surveywts_error_no_strata_variables` — checked before cell-matching logic |
| A `targets` column name not found in `data` | Error: `surveywts_error_targets_variable_not_found` (pre-join check; same class as greg) |
| NA in a stratification variable | Error: `surveywts_error_variable_has_na` |
| Cell in `data` not in `targets` | Error: `surveywts_error_population_cell_missing` |
| Cell in `targets` not in `data` | Error: `surveywts_error_population_cell_not_in_data` |
| Duplicate cells in `targets` | Error: `surveywts_error_population_cell_duplicate` |
| Cell with zero weighted count | Error: `surveywts_error_empty_stratum` (defensive `# nocov` guard as in `poststratify()`) |
| Single stratification variable | Accepted; behaves as single-variable poststratification |
| `type = "prop"` targets summing to != 1 | Error: `surveywts_error_population_totals_invalid` |

## VI. `calibrate()` — Thin Dispatcher

### Signature

```r
calibrate(
  data,
  targets,
  weights          = NULL,
  wt_name          = "wts",
  type             = c("prop", "count"),
  method           = c("greg", "rake", "poststrat"),
  reference_design = NULL,
  ...
)
```

### Design

Follows the `create_replicate_weights()` dispatcher pattern exactly:

1. `rlang::arg_match(method)` resolves and validates the `method` value.
2. `switch()` dispatches to the appropriate function, passing `data` and
   all `...` arguments through.
3. All validation, defaults, and error messages are handled by the dispatched
   function. `calibrate()` itself performs no validation beyond method matching.

```
method = "greg"       → calibrate_greg(data, ...)
method = "rake"       → calibrate_rake(data, ...)
method = "poststrat"  → calibrate_poststrat(data, ...)
```

Unknown or misspelled `method` values produce R's native `rlang::arg_match()`
error. Unknown `...` arguments for the selected method produce R's native
"unused argument" error from the receiving function.

**Default method:** GREG is the default because it is the most general linear
calibration estimator; rake and poststrat are restricted special cases of GREG.

**NSE forwarding:** The `weights` argument is a tidy-select bare name (NSE).
The dispatcher must capture it with `rlang::enquo(weights)` and inject it into
the dispatched call with `!!` so the receiving function sees the original
unevaluated symbol, not the variable name `weights`. Example:
`calibrate_greg(data, targets = targets, weights = !!rlang::enquo(weights), ...)`

### Arguments

| Arg | Type | Default | Description |
|-----|------|---------|-------------|
| `data` | any | required | Passed as-is to the dispatched function. |
| `targets` | named list or `data.frame` | required | Passed as-is to the dispatched function. |
| `weights` | tidy-select bare name | `NULL` | Passed as-is to the dispatched function. |
| `wt_name` | `character(1)` | `"wts"` | Passed as-is to the dispatched function. |
| `type` | `character(1)` | `"prop"` | Passed as-is to the dispatched function. |
| `method` | `character(1)` | `"greg"` | Which calibration family to dispatch to. |
| `reference_design` | `survey_taylor` or `NULL` | `NULL` | Passed as-is to the dispatched function. |
| `...` | any | — | Method-specific arguments passed as-is to the dispatched function. |

### Returns

Returns whatever the dispatched function returns (see §III–V for each
function's return contract).

### Errors

| Class | Trigger condition |
|-------|-------------------|
| (native `rlang::arg_match` error) | `method` not in `c("greg", "rake", "poststrat")` |
| (any error from dispatched function) | Propagated unchanged from `calibrate_greg()`, `calibrate_rake()`, or `calibrate_poststrat()` |

### Edge cases

`calibrate()` is a thin pass-through. All edge cases are handled by the
dispatched function. The only behavior that `calibrate()` itself is
responsible for is method resolution.

## VII. History Entry Specification

All three substantive functions produce a history entry appended to
`weighting_history`. The `operation` field values are:

| Function | `operation` value |
|----------|------------------|
| `calibrate_greg()` | `"calibrate_greg"` |
| `calibrate_rake()` | `"calibrate_rake"` |
| `calibrate_poststrat()` | `"calibrate_poststrat"` |

These values replace the old operation strings (`"calibration"`, `"raking"`,
`"poststratify"`). Any code that reads `weighting_history` and checks the
`operation` field string must be updated if it existed (no known callers in
this codebase outside the test suite).

The `targets` field in history `parameters` stores a **Format A named list**
for `calibrate_greg()` and `calibrate_rake()`, and a **data frame** for
`calibrate_poststrat()`, because the formats are structurally incompatible
(marginals vs. joint cells). This asymmetry is intentional.

## VIII. Error Class Assignment Clarification

The error class `surveywts_error_margins_format_invalid` is used by
`calibrate_greg()` when `targets` is neither a named list nor a valid Format B
data frame. This is the same structural condition as in `calibrate_rake()`.
The class name is not changed; only the "Thrown by" column in
`plans/error-messages.md` is updated to list both `calibrate_greg()` and
`calibrate_rake()`.

The `plans/error-messages.md` "Thrown by" column must be updated to replace
old function names with new ones throughout.
