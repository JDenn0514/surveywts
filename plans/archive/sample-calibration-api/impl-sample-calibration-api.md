# Implementation Plan — sample-calibration-api

**Status**: DRAFT
**Spec**: `plans/spec-sample-calibration-api.md` (v1.2, SPEC_READY)
**Test-spec**: `plans/test-spec-sample-calibration-api.md`
**Target version**: 0.6.0.9000

## Overview

This plan delivers a complete API rewrite of `calibrate_to_survey()` and
`calibrate_to_estimate()`. Both functions receive new signatures (renamed
arguments, new arguments, removed arguments), new validation logic, renamed
history operation fields, and new roxygen documentation. The existing test
file is fully replaced to exercise the new API. All changes land in one PR
because the two functions share helper changes, a single test file, and
tightly coupled error-class additions.

### Notes (implementation details for the builder)

#### Bundling rationale (override of spec §Pipeline split recommendation)

`spec-sample-calibration-api.md §Pipeline split` recommends two PRs (one per function). This plan intentionally overrides that recommendation: both functions share `test-sample-calibration.R` as their single test file, so splitting would create overlapping write surfaces between the two PRs — a pipeline constraint violation. Bundling is the correct call; the shared test file, helper changes, and error-class additions cannot be cleanly separated without also splitting the test file, which adds complexity with no benefit.

#### `make_replicate_design` helper signature change

The current helper uses `n_replicates` as a parameter and hardcodes `n =
200L`. The test-spec defines the new signature as `make_replicate_design(n =
200L, seed = 42L)` with `replicates` fixed at `50L`.

Correct implementation (the test-spec's helper pseudocode omits the taylor
wrapping step, but `create_bootstrap_weights` rejects data frames per
`surveywts_error_not_survey_design`):

```r
make_replicate_design <- function(n = 200L, seed = 42L) {
  df <- make_surveywts_data(n = n, seed = seed)
  taylor <- surveycore::survey_taylor(
    data = df,
    variables = list(weights = "base_weight")
  )
  create_bootstrap_weights(taylor, replicates = 50L)
}
```

All existing test blocks that call `make_replicate_design(n_replicates = ...)` will be
replaced with the new API.

#### `test_invariants()` extension

The current `survey_replicate` branch in `test_invariants()` only checks
`repweights` structure. The test-spec requires the full branch:

if (S7::S7_inherits(obj, surveycore::survey_replicate)) {

#### `calibrate_to_survey()` — key implementation points

**Signature**:
```r
calibrate_to_survey(
  primary_design,
  control_design,
  variables,
  method        = c("rake", "linear", "logit"),
  bounds        = c(-Inf, Inf),
  unit_scale    = NULL,
  reference_design = NULL,
  control       = list()
)
```

**`variables` resolution** (tidy-select bare names → character vector):
```r
vars_sel <- tidyselect::eval_select(rlang::enquo(variables), data = primary_design@data)
vars_chr <- names(vars_sel)
# fire surveywts_error_variables_not_found if length(vars_chr) == 0
```
Then build formula for svrep: `reformulate(vars_chr)`.

**`method` matching**: use `rlang::arg_match()` (not `match.arg()`).

**`bounds` format**: the new user-facing API takes `c(L, U)`. Check svrep
>= 0.6.0's expected format for `calibrate_to_sample()` and pass accordingly.
If svrep still expects a named list, convert internally.

**`control` unknown-key warning + extraction pattern** (run before merging with
defaults):
```r
known_keys <- c("maxit", "epsilon", "control_col_matches")
unknown_keys <- setdiff(names(control), known_keys)
for (k in unknown_keys) {
  cli::cli_warn(
    c("!" = "Unknown {.arg control} key {.val {k}} will be ignored."),
    class = "surveywts_warning_control_param_ignored"
  )
}
control_col_matches <- control[["control_col_matches"]]  # NULL if absent
control <- control[intersect(names(control), c("maxit", "epsilon"))]
control <- utils::modifyList(list(maxit = 50L, epsilon = 1e-7), control)
```

**`reference_design` storage** (provenance only, not used in calibration):
```r
targets_from_reference <- !is.null(reference_design)
# stored in history parameters$targets_from_reference and parameters$reference_design
```

**Remove replicate count mismatch error**: the old `surveywts_error_replicate_count_mismatch`
check is REMOVED. Svrep handles count mismatches natively. Count mismatches do NOT
trigger `surveywts_warning_replicate_scheme_mismatch` (that warning fires only
for replicate TYPE differences).

**Hard error vs convergence split**:
- Convergence warning from svrep (`grepl("converge", msg, ignore.case = TRUE)`) →
  `surveywts_error_calibration_not_converged`
- Hard error from svrep (svrep `stop()`s) →  `surveywts_error_calibration_failed`
  (this was previously also `surveywts_error_calibration_not_converged` — MUST be changed)

**History entry**:
- `operation = "calibrate_to_survey"` (not `"sample_calibration_replicate"`)
- `parameters` must include: `variables` (character vector), `method`, `bounds`,
  `unit_scale`, `n_replicates`, `control_design_class`, `n_replicates_control`,
  `targets_from_reference`, `reference_design`, `control` (merged defaults, WITHOUT
  `control_col_matches`)
- `before_stats`, `after_stats` from `.compute_weight_stats()` (11-key named list)

**Negative weight clipping** fires only for `method = "linear"` after the full-sample
weight extraction, before writing back.

**Validation order** (strict):
1. `primary_design` class
2. `control_design` class
3. `reference_design` class (if non-`NULL`)
4. `unit_scale` validation (if non-`NULL`)
5. `control` unknown-key warning + extraction of `control_col_matches` + merge with defaults
6. `variables` tidy-select resolution and existence check
7. Replicate-scheme type mismatch warning (if types differ)
8. Call svrep; catch convergence (→ `_not_converged`) and hard errors (→ `_failed`)
9. Warn on negative full-sample weights
10. Write weights back, append history

#### `calibrate_to_estimate()` — key implementation points

**Signature**:
```r
calibrate_to_estimate(
  design,
  targets,
  vcov_estimate,
  method        = c("rake", "linear", "logit"),
  bounds        = c(-Inf, Inf),
  unit_scale    = NULL,
  reference_design = NULL,
  control       = list()
)
```

**`targets` → svrep call conversion**: svrep's `calibrate_to_estimate()` (current
surveywts version) expects `estimate` (named numeric vector) and `vcov_estimate`.
Convert internally:
```r
estimate    <- unlist(targets)  # names like "age_group18-34", "sexF"
cal_formula <- reformulate(names(targets))
```
Then pass `estimate`, `vcov_estimate`, and `cal_formula` to svrep.

Note: `unlist()` preserves the order contract (outer-list order, then within-element
order) so the `vcov_estimate` dimension check against `length(unlist(targets))` is
the same as the dimension of what svrep will receive.

**`control` unknown-key warning + extraction** (analogous to `calibrate_to_survey`):
```r
known_keys <- c("maxit", "epsilon", "col_selection")
unknown_keys <- setdiff(names(control), known_keys)
for (k in unknown_keys) {
  cli::cli_warn(
    c("!" = "Unknown {.arg control} key {.val {k}} will be ignored."),
    class = "surveywts_warning_control_param_ignored"
  )
}
col_selection <- control[["col_selection"]]
control <- control[intersect(names(control), c("maxit", "epsilon"))]
control <- utils::modifyList(list(maxit = 50L, epsilon = 1e-7), control)
```

**Error class change**: `design` not replicate now throws `surveywts_error_design_not_replicate`
(the current code incorrectly throws `surveywts_error_primary_not_replicate`).

**Targets levels mismatch check** (`surveywts_error_targets_levels_mismatch`): compare
`names(targets[[var]])` against the actual levels in `design@data[[var]]`. For factors:
`levels(design@data[[var]])`. For character: `unique(design@data[[var]])`. Both missing
levels (in data but not in targets) and extra levels (in targets but not in data) trigger
the error. Run this check after the variable existence check (step 6a in spec).

**History entry**:
- `operation = "calibrate_to_estimate"` (not `"sample_calibration_estimate"`)
- `parameters` must include: `variables` (`names(targets)`), `method`, `bounds`,
  `unit_scale`, `n_replicates`, `targets` (the named list), `vcov_dim`
  (`dim(vcov_estimate)`), `targets_from_reference`, `reference_design`, `control`
  (merged defaults, WITHOUT `col_selection`)

**Validation order** (strict):
1. `design` class check → `surveywts_error_design_not_replicate`
2. `reference_design` class check (if non-`NULL`)
3. `unit_scale` validation (if non-`NULL`)
4. `control` unknown-key warning + extraction of `col_selection` + merge with defaults
5. `targets` named-list check (including empty-list check)
6. `targets` element named-numeric check
6b. `targets` element positivity check
7. `targets` variable names existence check in `design@data`
7a. `targets` level-label mismatch check
8. `vcov_estimate` NA check
9. `vcov_estimate` dimension check (`length(unlist(targets)) x length(unlist(targets))`)
10. `vcov_estimate` symmetry check (tolerance 1e-8)
11. `vcov_estimate` PD check (Cholesky)
12. Call svrep; catch convergence (→ `_not_converged`) and hard errors (→ `_failed`)
13. Warn on negative full-sample weights
14. Write weights back, append history

#### Mocking svrep for convergence and hard-error tests

Use `testthat::with_mocked_bindings()` (available since testthat 3.1.1; already required at >= 3.2.0 — no new dependency). The `.package = "svrep"` argument replaces the binding in svrep's own namespace, so `svrep::calibrate_to_sample()` and `svrep::calibrate_to_estimate()` calls inside the surveywts functions will use the mock.

**Convergence mock** — emit a warning containing `"converge"` and return `NULL` (the handler runs before the return value is used):

```r
testthat::with_mocked_bindings(
  calibrate_to_sample = function(...) {
    warning("Calibration did not converge", call. = FALSE)
    NULL
  },
  .package = "svrep",
  {
    expect_error(
      calibrate_to_survey(primary, control, variables = c(sex)),
      class = "surveywts_error_calibration_not_converged"
    )
  }
)
```

**Hard-error mock** — call `stop()` unconditionally:

```r
testthat::with_mocked_bindings(
  calibrate_to_sample = function(...) stop("svrep internal error"),
  .package = "svrep",
  {
    expect_error(
      calibrate_to_survey(primary, control, variables = c(sex)),
      class = "surveywts_error_calibration_failed"
    )
  }
)
```

Apply the same pattern for `calibrate_to_estimate()` tests, mocking `calibrate_to_estimate` in the `"svrep"` namespace.

#### Bounds passthrough

The spec says `bounds = c(L, U)` is "passed as the `bounds` argument to svrep."
If svrep's `calibrate_to_sample()` / `calibrate_to_estimate()` still expects a
named list internally, add a conversion step. Check svrep >= 0.6.0 docs or source
to determine the current expected format, then pass accordingly. Do NOT expose the
format mismatch to the user — the surveywts public API is always `c(L, U)`.
