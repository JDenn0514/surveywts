## Notes for Tester

- The `make_nonprob_replicate_design()` helper now manually sets `@variables$scale <- 1/R` because `create_bootstrap_weights(type = "quasi-randomization")` does not populate `@variables$scale` on the returned `survey_nonprob`. The value `1/R` matches the bootstrap scale constant convention used by svrep for probability-sample designs (verified: `make_replicate_design(R = 50)@variables$scale == 0.02 == 1/50`).
- The svrep delegation path is unchanged for `targets = NULL` (and is also called for `targets != NULL` as a stub per the impl plan — PR 2 replaces this with the Opsomer algorithm).
- Regression guard tests (section 25) do NOT use `skip_if_not_installed("svrep")` as specified, making them forward-compatible when svrep delegation is removed in PR 2.
- The `.validate_targets_for_opsomer()` NULL names guard (`tgt_names_raw <- names(targets); if (is.null(tgt_names_raw) || ...)`) is required because `names(list(c(1000, 2000)))` returns `NULL` (not a character of `""`), so `!all(nzchar(...))` alone would silently pass.
