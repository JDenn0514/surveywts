## Overview

This plan delivers the Propensity phase: a new `ipw()` function for constructing
inverse probability weights for non-probability samples (via pseudo-likelihood
Newton-Raphson), and a full implementation of `adjust_nonresponse(method =
"propensity")` replacing its current stub. Two utils.R changes are co-delivered
with `ipw()` (extending `.validate_formula_variables()` and `.format_history_step()`).
Two PRs total, sequenced so infrastructure ships first.

**Task 1.8** — Create `R/nonprob-ipw.R`. Define `.fit_participation_propensity()` first
(file-local, before `ipw()`). Add roxygen `@keywords internal` + `@noRd`. Implement the
Newton-Raphson pseudo-likelihood loop from spec §III Weight Formula:

```r
.fit_participation_propensity <- function(
  selection, nps_data, ref_data, ref_weights, method, maxit, epsilon
) {
  X_nps <- stats::model.matrix(selection, data = nps_data)
  X_ref <- stats::model.matrix(selection, data = ref_data)
  d_ref <- ref_weights
  gamma <- rep(0, ncol(X_nps))
  link  <- stats::binomial(link = method)$linkinv
  converged <- FALSE

  for (iter in seq_len(maxit)) {
    pi_ref <- link(X_ref %*% gamma)
    score  <- colSums(X_nps) - drop(t(X_ref) %*% (d_ref * pi_ref))
    hess   <- -crossprod(X_ref, X_ref * (d_ref * pi_ref * (1 - pi_ref)))
    delta  <- tryCatch(
      solve(hess, score),
      error = function(e) cli::cli_abort(
        c("x" = "Propensity Hessian is singular: {e$message}",
          "i" = "Collinear or degenerate covariates in {.arg selection}.",
          "v" = "Simplify {.arg selection} or check for constant covariate columns."),
        class = "surveywts_error_propensity_hessian_singular"
      )
    )
    gamma <- gamma - delta
    if (max(abs(delta)) < epsilon) {
      converged <- TRUE
      break
    }
  }
  list(
    scores      = drop(link(X_nps %*% gamma)),
    converged   = converged,
    final_delta = max(abs(delta))
  )
}
```

*(The NR non-convergence warning is emitted in `ipw()` after the call by checking
`result$converged`. The helper always returns a named list; `ipw()` extracts
`$scores` for weight computation.)*

### Implementation notes

- **Reference weights extraction:** `reference@variables$weights` gives the weight
  column name; `reference@data[[reference@variables$weights]]` gives the numeric vector.
- **`n_trimmed` formula:** `.trim_weights_internal()` returns `list(weights, has_trimmed)`.
  The `has_trimmed` field is a logical vector. `n_trimmed = sum(result$has_trimmed)`.
  Do NOT use `result$n_trimmed` — that field does not exist.
- **NR convergence check placement:** The non-convergence warning is emitted by `ipw()`
  after `.fit_participation_propensity()` returns, by tracking whether the loop reached
  `maxit` without satisfying `max(abs(delta)) < epsilon`. The helper should return the
  final scores plus a convergence flag (or `ipw()` can track iterations via a counter
  returned from the helper). One clean option: have the helper return a named list
  `list(scores = ..., converged = <logical>, final_delta = <numeric>)` and have `ipw()`
  check `result$converged` to decide whether to warn.
- **`tryCatch` on `solve()`:** The singular Hessian error must use `surveywts_error_propensity_hessian_singular`. Do not propagate the raw `solve.default` error.
- **Factor level check (Behavior Rule 8):** Use `levels(factor(data[[var]]))` vs
  `levels(factor(reference@data[[var]]))`. Levels in `data` but not in `reference@data`
  → error. Levels in `reference@data` only → no action.
- **`estimated_population_size` before trim:** Compute `sum(w)` before calling
  `.trim_weights_internal()`. Store as `estimated_population_size` in history regardless
  of `trim = TRUE/FALSE`.
- **`survey_nonprob` constructor:** Use the surveycore internal constructor pattern
  consistent with other functions in this package that return `survey_nonprob`.
- **NR helper return value:** The helper spec says "returns named numeric vector of length
  `nrow(nps_data)`". If tracking convergence in the helper, add a `converged` attribute
  or return a named list — but keep the return contract simple. Simplest: return a list
  `list(scores, converged, final_delta)` from the helper; `ipw()` extracts `$scores`.
