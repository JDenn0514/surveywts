# Spec — sample-calibration-api

**Status**: SPEC_READY
**Version**: 1.2
**Target version**: 0.6.0.9000
**PR range**: PR 1

## Scope

### In

- `calibrate_to_survey()`: replace `formula` parameter with `variables`
  (tidy-select bare names); rename accepted `method` value `"raking"` to
  `"rake"`; change `bounds` format from `list(lower, upper)` to `c(L, U)`;
  add `unit_scale`, `reference_design`; expose `control_col_matches` via
  `control`; add unknown-key warning for `control`; remove replicate-count
  mismatch error (svrep handles mismatches); rename history `operation` field;
  add `@examples`, `@references`, `@details`.

- `calibrate_to_estimate()`: replace `formula + estimate` with `targets`
  (named list of count totals); rename accepted `method` value `"raking"` to
  `"rake"`; change `bounds` format from `list(lower, upper)` to `c(L, U)`;
  add `unit_scale`, `reference_design`; expose `col_selection` via `control`;
  add unknown-key warning for `control`; rename history `operation` field;
  split convergence error into two classes; add `@examples`, `@references`,
  `@details`.

- Update `plans/error-messages.md` with all new, renamed, and retired classes.

### Out

- No changes to `calibrate_linear()`, `calibrate_logit()`, `calibrate_rake()`,
  `poststratify()`, `calibrate()`, or any other exported function.
- No changes to `survey_replicate` class definition or construction.
- No `bounds_scale` argument (svrep/grake accepts only `c(lower, upper)` scalar
  bounds; per-unit or scale-variant bounds are not supported).

## Function contracts

### `calibrate_to_survey(primary_design, control_design, variables, method, bounds, unit_scale, reference_design, control)`

- **Signature**:
  ```r
  calibrate_to_survey(
    primary_design,
    control_design,
    variables,
    method        = c("rake", "linear", "logit"),
    bounds        = c(-Inf, Inf),
    unit_scale    = NULL,
    reference_design = NULL,
    control       = list()
  )
  ```

- **Arguments**:

  - `primary_design` — A `survey_replicate` design object (from surveycore).
    The design whose full-sample and replicate weights will be calibrated.
    Any other class triggers `surveywts_error_primary_not_replicate`.

  - `control_design` — A `survey_replicate` design object (from surveycore).
    Provides the calibration targets; each replicate of `primary_design` is
    calibrated to the corresponding replicate of `control_design`, propagating
    the variance of the control totals into the variance estimates. Any other
    class triggers `surveywts_error_control_not_replicate`.

    Why a replicate design is required: propagating the uncertainty of the
    control-survey totals into the final variance estimate requires both a
    full-sample calibration and a separate calibration of each primary
    replicate to the corresponding control replicate. A Taylor-linearization
    design carries no replicates, so it cannot propagate control-survey
    variance.

  - `variables` — `<tidy-select>` Column selection identifying calibration
    variables, given as bare names (e.g., `c(age_group, sex)`). All selected
    variables must exist in `primary_design@data`. A variable name that does
    not resolve in the data triggers `surveywts_error_variables_not_found`. An
    empty selection triggers `surveywts_error_variables_not_found`.

  - `method` — Character scalar. Calibration algorithm. One of `"rake"`
    (iterative multiplicative; always positive weights), `"linear"` (one-step
    GREG; may produce negative weights), or `"logit"` (bounded iterative;
    requires finite `bounds`). Matched with `rlang::arg_match()`. Default
    `"rake"`.

  - `bounds` — Length-2 numeric vector `c(L, U)`. Default `c(-Inf, Inf)`
    (unbounded). Passed as the `bounds` argument to svrep. For `method =
    "logit"`, both `L` and `U` must be finite; using the default infinite
    bounds with `"logit"` will result in a hard error from svrep
    (`surveywts_error_calibration_failed`). `bounds_scale` is not supported;
    only scalar `c(L, U)` bounds (applied uniformly) are accepted.

  - `unit_scale` — `NULL` (default) or a positive numeric vector of length
    equal to the number of rows in `primary_design@data`. Per-observation
    scaling factors passed to svrep's `variance` argument. `NULL` is
    equivalent to all-ones. In linear GREG calibration (`method = "linear"`),
    `unit_scale[k]` serves as the variance-model parameter q_k:
    Var(y_k | x_k) ∝ q_k, so units with larger values contribute less to the
    calibration adjustment; all-ones (or `NULL`) corresponds to
    homoscedasticity. For `method = "rake"` and `method = "logit"`, svrep
    accepts the `variance` argument but its practical effect is
    implementation-defined; the parameter may be ignored for non-GREG methods.
    Triggers `surveywts_error_unit_scale_invalid` if not `NULL` and: not
    numeric, wrong length, contains `NA`, or contains non-positive values.

  - `reference_design` — A `survey_taylor` object or `NULL` (default). When
    non-`NULL`, stored in the history entry `parameters$reference_design` with
    `parameters$targets_from_reference = TRUE`. When `NULL` (the default),
    `parameters$targets_from_reference = FALSE` and
    `parameters$reference_design = NULL`. Not used in calibration; used
    for provenance tracking only. Any non-`NULL` non-`survey_taylor` value
    triggers `surveywts_error_reference_design_not_taylor`.

  - `control` — Named list of convergence parameters. Known keys:
    - `maxit` — integer, default `50L`. Maximum iterations. Matches svrep's
      own default (`maxit = 50`) — passing surveywts's default is equivalent
      to relying on svrep's default.
    - `epsilon` — numeric, default `1e-7`. Convergence threshold. Matches
      svrep's own default (`epsilon = 1e-07`).
    - `control_col_matches` — integer vector or `NULL` (default). When
      non-`NULL`, passed to svrep to specify which control replicate column
      each primary replicate is matched to, enabling reproducible matching.
      When absent (or `NULL`), svrep uses random matching — results are
      non-deterministic; two calls with identical inputs can produce different
      calibrated weights. Set `control_col_matches` to a fixed integer vector
      to ensure reproducibility.

    Any key not in `{maxit, epsilon, control_col_matches}` triggers one
    `surveywts_warning_control_param_ignored` per unknown key. Keys are
    stripped after warning; only known keys are forwarded.

- **Returns**: A `survey_replicate` object (same class as `primary_design`).
  The full-sample weight column (`primary_design@variables$weights`) and all
  replicate weight columns (`primary_design@variables$repweights`) are updated
  in the returned object. A history entry is appended to
  `primary_design@metadata@weighting_history` with:
  - `operation = "calibrate_to_survey"`
  - `parameters` containing: `variables` (character vector), `method`,
    `bounds`, `unit_scale`, `n_replicates`, `control_design_class`,
    `n_replicates_control`, `targets_from_reference`, `reference_design`,
    `control` (the merged list of effective values for all known keys
    including defaults for any omitted keys — e.g.,
    `list(maxit = 50L, epsilon = 1e-7)` when `control = list()` was passed —
    excluding `control_col_matches`)
  - `weight_stats` — a named list with two elements, `before` and `after`,
    each produced by `.compute_weight_stats()` applied to the full-sample
    weights before and after calibration. Each element is a named list with
    11 keys: `n`, `n_positive`, `n_zero`, `mean`, `cv`, `min`, `p25`, `p50`,
    `p75`, `max`, `ess` (effective sample size). Accessed as
    `entry$weight_stats$before` and `entry$weight_stats$after`.

  - `parameters$reference_design` — when `reference_design` is non-`NULL`,
    stored as a provenance proxy: `list(class = <class_string>, n = <nrow>)`.
    Not the full `survey_taylor` object (large objects are not serialized into
    history). When `reference_design` is `NULL`, `parameters$reference_design`
    is `NULL`.

  The calibration intercept constraint forces the calibrated weight sum to
  equal the control survey's weight sum, not the primary design's original
  weight sum.

  If `primary_design` has more replicates than `control_design`, svrep
  duplicates control replicates to fill. Note: duplicate control replicates
  understate the control-survey variance contribution; users who require
  precise variance propagation should construct designs with matched replicate
  counts. If `primary_design` has fewer, some primary replicates are not
  matched. No error is thrown for count mismatches;
  `surveywts_warning_replicate_scheme_mismatch` is still emitted when replicate
  types differ (e.g., `"bootstrap"` vs `"JK1"`).

- **Errors**:

  | Class | Trigger condition |
  |-------|-------------------|
  | `surveywts_error_primary_not_replicate` | `primary_design` is not `survey_replicate` |
  | `surveywts_error_control_not_replicate` | `control_design` is not `survey_replicate` |
  | `surveywts_error_variables_not_found` | Any selected variable name is absent from `primary_design@data`, or selection is empty |
  | `surveywts_error_unit_scale_invalid` | `unit_scale` is non-`NULL` and not numeric, wrong length, has `NA`, or has non-positive values |
  | `surveywts_error_reference_design_not_taylor` | `reference_design` is non-`NULL` and not `survey_taylor` |
  | `surveywts_error_calibration_not_converged` | Convergence flag: svrep emits a convergence warning (algorithm did not converge within `maxit` iterations). Detection uses `grepl("converge", msg, ignore.case = TRUE)` on svrep's warning text; svrep's partial convergence result is discarded. |
  | `surveywts_error_calibration_failed` | Hard execution: svrep throws an error during calibration (e.g., infinite bounds with `method = "logit"`, numerically degenerate data) |

- **Warnings**:

  | Class | Trigger condition |
  |-------|-------------------|
  | `surveywts_warning_replicate_scheme_mismatch` | `primary_design` and `control_design` have different replicate types (e.g., `"bootstrap"` vs `"JK1"`) |
  | `surveywts_warning_negative_calibrated_weights` | `method = "linear"` and any full-sample calibrated weight is negative; negative weights are clipped to `.Machine$double.eps`. Note: clipping breaks the calibration constraint — the calibrated weight sum will exceed the target total after clipping. |
  | `surveywts_warning_control_param_ignored` | A `control` list key is not in `{maxit, epsilon, control_col_matches}`; one warning per unknown key |

- **Edge cases**:
  - `primary_design` and `control_design` have different replicate counts: no
    error; svrep handles the mismatch (duplication or partial matching);
    `surveywts_warning_replicate_scheme_mismatch` is NOT emitted for count
    mismatches (only type mismatches).
  - `variables` selects a single variable: valid; treated the same as multiple
    variables.
  - `control_col_matches` in `control`: extracted and passed to svrep;
    stripped from the `control` list stored in the history entry.
  - `bounds = c(-Inf, Inf)` with `method = "logit"`: svrep raises a hard
    error; surfaced as `surveywts_error_calibration_failed`.
  - Empty `control = list()`: defaults applied; no warning.

### `calibrate_to_estimate(design, targets, vcov_estimate, method, bounds, unit_scale, reference_design, control)`

- **Signature**:
  ```r
  calibrate_to_estimate(
    design,
    targets,
    vcov_estimate,
    method        = c("rake", "linear", "logit"),
    bounds        = c(-Inf, Inf),
    unit_scale    = NULL,
    reference_design = NULL,
    control       = list()
  )
  ```

- **Arguments**:

  - `design` — A `survey_replicate` design object (from surveycore). The
    design whose full-sample and replicate weights will be calibrated. Any
    other class triggers `surveywts_error_design_not_replicate`.

    Why a replicate design is required: the uncertainty in the control totals
    (captured by `vcov_estimate`) is propagated into the final variance estimate
    by perturbing each replicate's calibration targets using draws from the
    estimated covariance structure. Without replicate weights, there is no
    mechanism to incorporate the additional uncertainty from the control survey.

  - `targets` — Named list of population count totals. Each element is a
    named numeric vector with strictly positive values. Element names are the
    calibration variable names; they must match column names in `design@data`.
    Inner names are the level labels; they must exactly match the levels
    present in the corresponding column (no missing levels, no extra levels).
    An empty list (`targets = list()`) triggers
    `surveywts_error_targets_not_named_list`.

    Example:
    ```r
    targets <- list(
      age_group = c("18-34" = 150, "35-54" = 200, "55+" = 150),
      sex       = c("F"     = 255, "M"     = 245)
    )
    ```

    Targets are always counts (totals). There is no `type` argument; the
    `calibrate_to_estimate()` function does not accept proportions.

    Triggers:
    - `surveywts_error_targets_not_named_list` — `targets` is not a named list
      (wrong class, any element name is missing/empty, or `targets` is an
      empty list with zero elements).
    - `surveywts_error_targets_element_not_named` — any element of `targets`
      is not a named numeric vector.
    - `surveywts_error_targets_element_not_positive` — any value in any
      element of `targets` is `<= 0` or `NA`.
    - `surveywts_error_variables_not_found` — any name in `targets` is absent
      from `design@data`.
    - `surveywts_error_targets_levels_mismatch` — for any variable in
      `targets`, the inner names of the element do not exactly match the set
      of levels in the corresponding `design@data` column. Missing levels (a
      level in the data but absent from `targets`) and extra levels (a name in
      `targets` but absent from the data) both trigger this error. Detected
      before calling svrep.

  - `vcov_estimate` — Numeric matrix. Variance-covariance matrix of the
    flattened `targets` vector. Must be symmetric (within 1e-8 tolerance) and
    positive definite.

    **Ordering contract**: rows and columns of `vcov_estimate` must correspond
    to the elements of `unlist(targets)` in the order produced by `unlist()`:
    outer list order (order of elements in `targets`), then within each
    element the order of the named vector. Example: for
    `targets = list(age_group = c("18-34" = 150, "35-54" = 200), sex = c("F" = 255, "M" = 245))`,
    the ordering is `age_group18-34, age_group35-54, sexF, sexM`. The matrix
    must be `length(unlist(targets)) x length(unlist(targets))`.

    Triggers:
    - `surveywts_error_vcov_has_na` — `vcov_estimate` has `NA` values.
    - `surveywts_error_vcov_dimension_mismatch` — dimensions are not
      `length(unlist(targets)) x length(unlist(targets))`.
    - `surveywts_error_vcov_not_symmetric` — max absolute asymmetry
      `max(|V - V^T|)` exceeds `1e-8`.
    - `surveywts_error_vcov_cholesky_failed` — `chol(vcov_estimate)` fails
      (matrix is singular or indefinite).

    After validation, `vcov_estimate` is passed directly to
    `svrep::calibrate_to_estimate()` as its `vcov_estimate` argument. Svrep
    generates replicate-level target perturbations internally via the Cholesky
    factor; surveywts does not implement perturbation sampling.

  - `method` — Character scalar. Calibration algorithm. One of `"rake"`,
    `"linear"`, or `"logit"`. Same semantics as in `calibrate_to_survey()`.
    Default `"rake"`.

  - `bounds` — Length-2 numeric vector `c(L, U)`. Default `c(-Inf, Inf)`.
    Same semantics as in `calibrate_to_survey()`.

  - `unit_scale` — `NULL` (default) or a positive numeric vector of length
    equal to `nrow(design@data)`. Per-observation scaling factors. Same
    semantics, validation, and statistical role as in `calibrate_to_survey()`:
    in linear GREG calibration, `unit_scale[k]` serves as the variance-model
    parameter q_k; for rake and logit, the practical effect is svrep
    implementation-defined.

  - `reference_design` — A `survey_taylor` object or `NULL` (default). Same
    semantics as in `calibrate_to_survey()`: when non-`NULL`,
    `parameters$targets_from_reference = TRUE`; when `NULL` (the default),
    `parameters$targets_from_reference = FALSE` and
    `parameters$reference_design = NULL`.

  - `control` — Named list. Known keys:
    - `maxit` — integer, default `50L`. Matches svrep's own default.
    - `epsilon` — numeric, default `1e-7`. Matches svrep's own default.
    - `col_selection` — integer vector or `NULL` (default). When non-`NULL`,
      passed to svrep to specify the column indices of a multivariate-normal
      draw matrix, enabling reproducible replicate-level perturbations.
      When absent (or `NULL`), svrep uses random draws — results are
      non-deterministic; two calls with identical inputs can produce different
      calibrated weights. Set `col_selection` to a fixed integer vector to
      ensure reproducibility.

    Any key not in `{maxit, epsilon, col_selection}` triggers one
    `surveywts_warning_control_param_ignored` per unknown key.

- **Returns**: A `survey_replicate` object (same class as `design`). The
  full-sample weight column and all replicate weight columns are updated. A
  history entry is appended to `design@metadata@weighting_history` with:
  - `operation = "calibrate_to_estimate"`
  - `parameters` containing: `variables` (names of `targets`), `method`,
    `bounds`, `unit_scale`, `n_replicates`, `targets` (the named list),
    `vcov_dim` (dimensions of `vcov_estimate`), `targets_from_reference`,
    `reference_design`, `control` (the merged list of effective values for all
    known keys including defaults for any omitted keys — e.g.,
    `list(maxit = 50L, epsilon = 1e-7)` when `control = list()` was passed —
    excluding `col_selection`)
  - `weight_stats` — a named list with two elements, `before` and `after`,
    each produced by `.compute_weight_stats()` applied to the full-sample
    weights before and after calibration. Each element is a named list with
    11 keys: `n`, `n_positive`, `n_zero`, `mean`, `cv`, `min`, `p25`, `p50`,
    `p75`, `max`, `ess` (effective sample size). Accessed as
    `entry$weight_stats$before` and `entry$weight_stats$after`.

  - `parameters$reference_design` — when `reference_design` is non-`NULL`,
    stored as a provenance proxy: `list(class = <class_string>, n = <nrow>)`.
    Not the full `survey_taylor` object. When `reference_design` is `NULL`,
    `parameters$reference_design` is `NULL`.

  Weight-sum conservation: svrep adds an implicit intercept constraint that
  aligns the total calibrated weight to the targets' implied population size.
  When all variables' level totals sum to the same N (internally consistent
  targets), the calibrated weight sum equals N. When targets are inconsistent
  (different variables imply different Ns), svrep's intercept handling
  determines the result — behavior is svrep-implementation-defined and should
  not be relied upon.

- **Errors**:

  | Class | Trigger condition |
  |-------|-------------------|
  | `surveywts_error_design_not_replicate` | `design` is not `survey_replicate` |
  | `surveywts_error_targets_not_named_list` | `targets` is not a named list, or any element name is `""` or missing, or `targets` is an empty list |
  | `surveywts_error_targets_element_not_named` | Any element of `targets` is not a named numeric vector (unnamed, or not numeric) |
  | `surveywts_error_targets_element_not_positive` | Any value in any element of `targets` is `<= 0` or `NA` |
  | `surveywts_error_variables_not_found` | Any name in `targets` is absent from `design@data` |
  | `surveywts_error_targets_levels_mismatch` | For any variable in `targets`, the inner names of the element do not exactly match the levels in `design@data` (missing levels in targets OR extra levels in targets not in data) |
  | `surveywts_error_vcov_has_na` | `vcov_estimate` has `NA` values (checked before dimension/symmetry/PD) |
  | `surveywts_error_vcov_dimension_mismatch` | `dim(vcov_estimate)` is not `c(k, k)` where `k = length(unlist(targets))` |
  | `surveywts_error_vcov_not_symmetric` | `max(|V - V^T|) > 1e-8` |
  | `surveywts_error_vcov_cholesky_failed` | `chol(vcov_estimate)` fails |
  | `surveywts_error_unit_scale_invalid` | `unit_scale` is non-`NULL` and not numeric, wrong length, has `NA`, or has non-positive values |
  | `surveywts_error_reference_design_not_taylor` | `reference_design` is non-`NULL` and not `survey_taylor` |
  | `surveywts_error_calibration_not_converged` | Convergence flag: svrep emits a convergence warning. Detection uses `grepl("converge", msg, ignore.case = TRUE)` on svrep's warning text; svrep's partial convergence result is discarded. |
  | `surveywts_error_calibration_failed` | Hard execution: svrep throws an error |

- **Warnings**:

  | Class | Trigger condition |
  |-------|-------------------|
  | `surveywts_warning_negative_calibrated_weights` | `method = "linear"` and any full-sample calibrated weight is negative; negative weights are clipped to `.Machine$double.eps`. Note: clipping breaks the calibration constraint — the calibrated weight sum will exceed the target total after clipping. |
  | `surveywts_warning_control_param_ignored` | A `control` list key is not in `{maxit, epsilon, col_selection}`; one warning per unknown key |

- **Edge cases**:
  - Single-variable `targets` (one-element list): valid; internally produces a
    formula with one term.
  - `targets = list()` (zero-element list): triggers
    `surveywts_error_targets_not_named_list` — an empty list is treated as
    vacuously unnamed (no elements → no named elements). Checked at the
    named-list validation step.
  - `targets` with a single-level variable: valid if svrep accepts it; no
    special handling by surveywts.
  - `vcov_estimate` is the identity matrix scaled by a small constant (zero
    uncertainty in estimates): valid; treated as any other PD matrix.
  - `bounds = c(-Inf, Inf)` with `method = "logit"`: svrep raises a hard
    error; surfaced as `surveywts_error_calibration_failed`.
  - `col_selection` in `control`: extracted and passed to svrep; stripped from
    the `control` list stored in the history entry.
  - Empty `control = list()`: defaults applied; no warning.

## Validation order

For both functions, checks run in the following order:

**`calibrate_to_survey()`**:
1. `primary_design` class check
2. `control_design` class check
3. `reference_design` check (if non-`NULL`)
4. `unit_scale` validation (if non-`NULL`)
5. `control` unknown-key warning + merge with defaults
6. `variables` resolution and existence check in `primary_design@data`
7. Replicate-scheme mismatch warning (if types differ)
8. Call svrep; catch convergence warning (-> `surveywts_error_calibration_not_converged`) and hard errors (-> `surveywts_error_calibration_failed`)
9. Warn on negative full-sample weights (`method = "linear"` only)
10. Write updated weights back, append history

**`calibrate_to_estimate()`**:
1. `design` class check
2. `reference_design` check (if non-`NULL`)
3. `unit_scale` validation (if non-`NULL`)
4. `control` unknown-key warning + merge with defaults
5. `targets` validation: named-list check (including empty-list check), then element named-numeric check, then element positivity check
6. `targets` variable names existence check in `design@data`
6a. `targets` level-label mismatch check (`surveywts_error_targets_levels_mismatch`): for each variable resolved in step 6, compare `names(targets[[var]])` to `unique(design@data[[var]])` (or `levels()` if factor); fire if any level is missing or extra
7. `vcov_estimate` NA check, dimension check, symmetry check, PD check
8. Call svrep; catch convergence warning (-> `surveywts_error_calibration_not_converged`) and hard errors (-> `surveywts_error_calibration_failed`)
9. Warn on negative full-sample weights (`method = "linear"` only)
10. Write updated weights back, append history

## Roxygen documentation requirements

Both functions must include:

- `@family sample-calibration`
- `@export`
- `@return` describing the returned `survey_replicate` and the appended
  history entry
- `@details` explaining why `survey_replicate` is required (replicate weights
  are needed to propagate the control-survey uncertainty)
- `@details` or inline `@param bounds` note that `bounds_scale` is not
  supported and only scalar `c(L, U)` bounds are accepted (svrep/grake
  limitation)
- `@references`:
  - Fuller, W.A. (1998). Replication variance estimation for two-phase
    samples. *Statistica Sinica*, 8, 1153--1164.
  - Opsomer, J.D. and Erciulescu, A. (2021). Replication variance estimation
    after sample-based calibration. *Survey Methodology*, 47, 265--277.
- `@examples` using the `api` dataset from the `survey` package (available
  via `survey::` without loading).

## Quality gates

- Both functions return a `survey_replicate` in all non-error paths.
- History entry `operation` is exactly `"calibrate_to_survey"` or
  `"calibrate_to_estimate"` (no other values).
- The `control` list stored in history never contains `control_col_matches`
  (for `calibrate_to_survey`) or `col_selection` (for `calibrate_to_estimate`);
  these are forwarding-only keys.
- `unit_scale` validation fires before any svrep call.
- `vcov_estimate` NA check precedes dimension, symmetry, and PD checks.
- `surveywts_error_calibration_failed` is thrown only for hard execution errors
  from svrep; `surveywts_error_calibration_not_converged` is thrown only when
  svrep emits a warning containing "converge".
- Negative full-sample weights are clipped to `.Machine$double.eps` after the
  warning is emitted; replicate weights are not clipped. Clipping breaks the
  calibration constraint (the calibrated weight sum will exceed the target
  total); this limitation is documented in the warning and `@details`.
