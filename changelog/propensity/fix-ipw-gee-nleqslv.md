# fix(weights): replace hand-coded GEE Newton-Raphson with nleqslv; default estimating_eq to "gee"

**Date**: 2026-06-24
**Branch**: feature/gee-nleqslv
**Phase**: Propensity

## Changes

- Replace hand-coded Newton-Raphson GEE loop in `.fit_participation_propensity()`
  with `nleqslv::nleqslv(method = "Newton")` using the analytical Jacobian. Newton
  method with double-dogleg global strategy converges in ~3 iterations regardless
  of reference weight scale (unit-scale or population-scale).
- Move outer saturation guard (scores at float boundary) from the shared iteration
  loop into the MLE branch only. The GEE path no longer has a saturation guard
  because nleqslv with Newton+dbldog never drives gamma to infinity.
- Remove inner `pi_nps <= eps` guard from the GEE branch (redundant with nleqslv
  safety checks).
- Change `estimating_eq` default from `"mle"` to `"gee"`. The first element of
  the character vector is now `"gee"`, so `match.arg()` picks it automatically.
- Update non-convergence warning: replace "max |delta|" label with "convergence
  diagnostic" to be accurate for both MLE (max abs step) and GEE (max abs
  score residual).
- Add `nleqslv (>= 3.3.2)` to `Imports:` in `DESCRIPTION`.
- Full Tier 3 roxygen2 documentation reorganization for `ipw()`: new
  `@section Algorithm:` (MLE and GEE subsections with `\deqn{}` formulas),
  `@section Convergence:` (replaces the "Newton-Raphson non-convergence" bold
  header in `@details`), `@section Missing Data:`, `@section Limitations:`,
  `@section Warnings:`. Remove `@note` block after migrating all content.
  Trim `@param reference`, `@param method`, `@param estimating_eq`,
  `@param missing_method`, `@param population_size` to terse summaries with
  forward references to named sections.

## Implementation Notes

- **Why `method = "Newton"` is required**: `nleqslv` default `method = "Broyden"`
  fails (termcd=4) when NPS covariate sums (~100-200) vs reference totals
  (~1,000,000) have a 5000x scale mismatch. Newton with the analytical Jacobian
  converges in ~3 iterations regardless of scale because the Jacobian correctly
  encodes the curvature at every iterate.
- **GEE convergence codes**: nleqslv `termcd` 1L = function-norm criterion;
  2L = step-size criterion. Both are declared converged. `termcd >= 3L` triggers
  the existing non-convergence warning.
- **Rule 15 (degenerate scores) on GEE path**: With Newton+dbldog, nleqslv
  never drives gamma to infinity, so `link(gamma_k)` stays well below
  `1 - .Machine$double.eps`. The Rule 15 check is a theoretical backstop
  that effectively never fires on the GEE path.
- **convergence diagnostic label**: MLE reports `max(abs(delta))` (step size);
  GEE reports `max(abs(gee_fit$fvec))` (score residual). Both are reported under
  the generic label "convergence diagnostic" so the message is accurate for
  both paths.
- **Default change impact**: Existing tests that relied on the implicit MLE
  default and were testing MLE-specific behavior (degenerate scores, Hessian
  singular, saturation guard) received explicit `estimating_eq = "mle"`.
