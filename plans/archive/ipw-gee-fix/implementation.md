## Summary

- Replaced hand-coded Newton-Raphson GEE loop in `.fit_participation_propensity()`
  with `nleqslv::nleqslv(method = "Newton")` using the analytical Jacobian
  `J = -X^T diag((1-pi)/pi) X`. Newton method with double-dogleg global strategy
  converges in ~3 iterations regardless of reference weight scale (unit-scale
  or population-scale, verified in AC-1 and AC-3 tests).
- Changed `estimating_eq` default from `"mle"` to `"gee"` by reordering the
  character vector to `c("gee", "mle")`; `match.arg()` picks the first element.
  Updated the non-convergence warning label from "max |delta|" to
  "convergence diagnostic" to be accurate for both paths.
- Moved the outer saturation guard (score boundary check) into the MLE branch
  only; removed the inner `pi_nps <= eps` guard from the GEE branch.
- Added `nleqslv (>= 3.3.2)` to `Imports:` in `DESCRIPTION`.
- Full Tier 3 roxygen2 documentation reorganization: new `@section Algorithm:`
  (MLE and GEE subsections with `\deqn{}` formulas), `@section Convergence:`,
  `@section Missing Data:`, `@section Limitations:`, `@section Warnings:`;
  removed `@note` block; trimmed verbose `@param` entries to terse summaries
  with forward references to named sections.

## Notes for tester

- `nleqslv` `method = "Newton"` is critical. The default `"Broyden"` method
  fails with population-scale reference weights (5000x scale mismatch between
  NPS covariate sums and reference totals). AC-2 exercises this path.
- The `termcd` convergence check is `%in% c(1L, 2L)` — both code 1
  (function-norm criterion) and code 2 (step-size criterion) are declared
  converged.
- GEE convergence diagnostic is `max(abs(gee_fit$fvec))` (max absolute score
  residual); MLE diagnostic is `max(abs(delta))` (max absolute step size).
  Both appear under the label "convergence diagnostic" in the warning message.
