## Summary

- Removed the redundant `|| inherits(data, "weighted_df")` guard in
  `.validate_replicate_input()` — `weighted_df` inherits from `data.frame` so
  the first condition already caught it.
- Collapsed `.extract_weight_vec()` to a one-liner by deleting the unreachable
  `# nocov` block that handled `weighted_df` and plain `data.frame` fallbacks.
- Updated roxygen `@param data` docs in `create_bootstrap_weights()` and
  `create_jackknife_weights()` to remove `weighted_df` from the error list.
- Deleted the dead `if (inherits(obj, "weighted_df"))` block from
  `test_invariants()` in `helper-test-data.R`.
- Renamed 5 tests from "rejects weighted_df input" to "rejects data.frame
  input", replacing `structure()` fake objects with plain `data.frame()`; new
  snapshots were accepted (same error message content, only test description
  changed).
