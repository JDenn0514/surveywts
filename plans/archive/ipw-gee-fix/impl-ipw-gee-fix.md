# Implementation Plan — ipw-gee-fix

**Status**: DRAFT
**Spec**: `plans/spec-ipw-gee-fix.md`
**Test-spec**: `plans/test-spec-ipw-gee-fix.md`
**Target version**: 0.2.0.9000

## Overview

This plan delivers the GEE-path rewrite described in `spec-ipw-gee-fix.md`.
The hand-coded Newton-Raphson loop in `.fit_participation_propensity()` is
replaced with `nleqslv::nleqslv()`, the outer saturation guard is moved inside
the MLE branch, and the inner GEE early-return guard is removed. Three
supporting changes accompany the code rewrite:

1. `nleqslv (>= 3.3.2)` is added to `DESCRIPTION` `Imports`.
2. The `estimating_eq` argument default is changed from `"mle"` to `"gee"`:
   the first element of the `match.arg()` vector becomes `"gee"`. Existing
   tests that call `ipw()` without specifying `estimating_eq` must be updated
   to set `estimating_eq = "mle"` explicitly if they test MLE-specific behavior.
3. Full roxygen2 documentation reorganization to meet Tier 3 requirements from
   `function-documentation.md`: create `@section Algorithm` (MLE + GEE
   subsections), `@section Convergence` (MLE + GEE paragraphs), `@section
   Missing Data`, and `@section Limitations`; trim mechanism content from
   `@param reference`, `@param method`, `@param estimating_eq`, `@param
   epsilon`, and `@param population_size`; remove the `@note` block (content
   moves to Limitations).

No new exported function signatures (beyond the default change), no new error
or warning classes.

### Implementation notes for `R/ipw.R`

**Guard relocation (GEE-2):** The outer saturation check currently sits at the
top of the `for` loop body before the `if/else` branch. Move it so it executes
only when `estimating_eq == "mle"`. The check itself is unchanged; only its
position changes.

**nleqslv call form (GEE-3):** Use the exact call signature from the spec:

```r
gee_fit <- nleqslv::nleqslv(
  x       = gamma,
  fn      = <score function>,
  jac     = <jacobian function>,
  control = list(maxit = maxit, xtol = epsilon, ftol = epsilon)
)
```

Both `xtol` and `ftol` are set to `epsilon` so nleqslv can declare convergence
on either criterion.

**Score function closure (GEE-4):** `fn` must close over `X_nps_fit`, `link`,
and `ref_totals`. `ref_totals` is computed once before the `nleqslv()` call
(Rule GEE-1, unchanged from current implementation).

**Jacobian closure (GEE-5):** `jac` must close over `X_nps_fit` and `link`.

**Result extraction (GEE-6, GEE-7):**
- `gamma <- gee_fit$x`
- `converged <- gee_fit$termcd %in% c(1L, 2L)`
- `final_delta <- max(abs(gee_fit$fvec))`

**Warning message label (GEE-7):** Update the non-convergence warning in
`ipw()` to use: `"convergence diagnostic = {round(fit$final_delta, 6)}"`.
Both the warning body and the `@details` paragraph must use this label.

**Inner guard removal (GEE-9):** Delete the `if (any(pi_nps <= eps)) { return(...) }`
block that currently exists inside the GEE branch.

**Default change (estimating_eq):**
In the `ipw()` function signature, change:
```r
estimating_eq = c("mle", "gee")
```
to:
```r
estimating_eq = c("gee", "mle")
```
`match.arg()` uses the first element as the default. Scan all existing calls
to `ipw()` in `tests/testthat/test-nonprob-ipw.R` that do not specify
`estimating_eq`; add `estimating_eq = "mle"` to any that test MLE-specific
behavior (e.g., weight values, convergence counts). The GEE-default tests added
in this PR already call `ipw()` with explicit `estimating_eq = "gee"`.

**Roxygen2 reorganization (full Tier 3 compliance):**

The documentation sections below must be created or updated. Content mapping
from the current source (lines 150–576 of `R/ipw.R`):

*`@section Algorithm` (CREATE — does not exist):*
- `**MLE**` subsection: pseudo-likelihood score equation (Chen, Li & Wu, 2020),
  Newton-Raphson loop, weight formula `w = 1/pi`. Move method literature-backing
  text from current `@param method`.
- `**GEE**` subsection: calibration estimating equations (Beresewicz et al.,
  2025), `nleqslv::nleqslv()` call, convergence criterion `termcd %in%
  c(1L, 2L)`, calibration guarantee `sum(w*x) = sum(d*x)`. Move Beresewicz
  simulation-result text from current `@param estimating_eq`.

*`@section Convergence` (CREATE — does not exist):*
- `**MLE**` paragraph: `max(abs(delta)) < epsilon`; non-convergence →
  `surveywts_warning_propensity_nr_no_convergence`; last iterate returned.
- `**GEE**` paragraph: delegated to `nleqslv::nleqslv()`; `termcd %in%
  c(1L, 2L)` = converged; `termcd >= 3` → same warning; last iterate returned.
  **Do not include** any note implying GEE fails with population-scale weights.
- Replaces the "Newton-Raphson non-convergence" bold header in current
  `@details`.

*`@section Missing Data` (CREATE — does not exist):*
- Covers: reference NA always listwise deletion; NPS NA methods omit/separate/impute;
  "separate" complete-case caveat (fitting on complete-case NPS, predicting for
  all rows). This is the reference for the behavior; `@param missing_method`
  stays concise on options only and links here.

*`@section Limitations` (CREATE — does not exist):*
- Move from current `@note`: MAR assumption, common support, independence of
  participation, non-overlapping samples.
- Move from current `@details`: sensitivity to propensity misspecification,
  high-dimensional selection.
- Remaining `@note` items not moving to Limitations — explicit dispositions:
  - **"Variance under-estimation"** → delete; content is fully covered (more
    thoroughly) by the variance-refit procedure in `@details`. Removing the
    shorter duplicate avoids contradicting the canonical refit guidance.
  - **"Weight interpretation"** (`w_i = 1 / P(in NPS | x_i)`) → move to
    `@section Algorithm` MLE subsection, alongside the weight formula `w = 1/pi`.
  - **"Pre-trim population size"** (`estimated_population_size = sum(w)` before
    trimming) → move to `@returns`, where output-object guarantees are documented.
- Remove the entire `@note` block after all items are migrated.

*`@details` (TRIM — keep):*
- Retain: variance estimation refit procedure (jackknife + bootstrap),
  unconditional pseudo-likelihood estimating equation, doubly robust
  recommendation, quantile balancing approximation.
- Remove after moving to sections: "Newton-Raphson non-convergence" paragraph
  (→ Convergence), misspecification sensitivity (→ Limitations),
  high-dimensional selection (→ Limitations).

*`@param` trims:*
- `@param reference`: keep type + "must have strictly positive design weights";
  remove methodology guidance, citation-based cautions, covariate measurement
  warning (→ `@section Limitations`).
- `@param method`: keep options list; remove literature-backing sentence
  (→ `@section Algorithm`).
- `@param estimating_eq`: keep the options and the calibration guarantee;
  update default to `"gee"`; remove Beresewicz simulation result sentence
  (→ `@section Algorithm`).
- `@param epsilon`: update description to cover both paths: for MLE, the
  convergence threshold on maximum absolute step size; for GEE, passed as
  both `xtol` and `ftol` to `nleqslv::nleqslv()`.
- `@param maxit`: update to cover both paths — for MLE, maximum
  Newton-Raphson iterations; for GEE, passed as `control$maxit` to
  `nleqslv::nleqslv()` (controls the solver's internal iteration budget,
  not an NR step count).
- `@param missing_method`: trim to a short options list with a forward
  reference to `@section Missing Data`; do not duplicate the mechanism
  description for each option in `@param` (the full "separate"
  complete-case caveat and reference-NA handling live in the section).
- `@param population_size`: keep type + behavior description; remove the
  manual IPW1 formula example (→ `@details`).

*`@examples` GEE block comment (UPDATE per spec):*
Remove the line "GEE converges best when NPS and reference are similar in size;
use balanced synthetic data here to illustrate the API." Replace with a comment
that does not imply a convergence limitation based on relative sample sizes.

*`@examples` default-change scan:*
After changing `estimating_eq` default to `"gee"`, scan all `@examples` calls
to `ipw()` that omit `estimating_eq` (currently: `result1`, `result2`,
`result_acs`, `result_omit`, `result_sep`, `result_imp`, `result_known_n`).
For each, confirm that GEE produces a valid result with the package dataset
used in that example. If a specific example is intended to demonstrate
MLE-specific behavior, add `estimating_eq = "mle"` explicitly. Examples that
demonstrate general `ipw()` usage may rely on the new GEE default without
adding an explicit argument.
