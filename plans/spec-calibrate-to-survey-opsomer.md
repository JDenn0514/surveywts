# Spec — calibrate-to-survey-opsomer

**Status**: SPEC_READY
**Target version**: 0.6.0.9000
**PR range**: PR 1–2

---

## Scope

### In
- Add `targets = NULL` argument to `calibrate_to_survey()` for fixed census margins
- Add `type = c("count", "prop")` argument to `calibrate_to_survey()` controlling
  interpretation of `targets` (ignored when `targets = NULL`)
- Implement Opsomer & Erciulescu (2022) replication variance adjustment for
  **all** calls: per-replicate calibration to Opsomer-perturbed control-survey
  margins (plus invariant fixed margins when `targets` is non-NULL), via
  `.calibrate_engine()`. When `targets = NULL`, the Opsomer path runs with
  `T_fixed = {}` — `method` and `algorithm` apply in both cases.
- Remove `svrep::calibrate_to_sample()` delegation; the function is now
  self-contained; svrep moves from `Imports` to `Suggests`
- Validate all new `targets` argument paths with new error classes
- Update roxygen2 documentation: new arguments, Algorithm section, updated
  Convergence section, updated `@references` block
- 6 new error classes have been added to `plans/error-messages.md`

### Out
- Changes to `calibrate_to_estimate()`
- Changes to any other function
- A new separate Opsomer dispatcher function
- Support for `survey_replicate` output class changes (output class follows
  `primary_design` class as before)
- Preserving bit-exact output for existing `targets = NULL` callers (the
  default method changes from svrep's linear GREG to rake with
  `algorithm = "classic_ipf"`; callers who need the prior behavior supply
  `method = "linear"`)

### Changelog notes (builder must include in NEWS.md)

- **Breaking default change:** The default calibration method for `targets = NULL`
  callers changes from linear GREG (svrep's default, equivalent to
  `method = "linear"`) to rake with `algorithm = "classic_ipf"`. This
  silently changes point estimates for all existing callers. Document
  prominently in NEWS.md. Callers who need the prior behavior must pass
  `method = "linear"` explicitly.
- **Additive history schema change:** The history entry for `targets = NULL`
  calls gains two new fields (`a_constants` and `K`). This is additive —
  existing key-name lookups on other fields are unaffected — but callers
  who iterate over or serialize history entries will see new fields.

## Function contracts

### `calibrate_to_survey(primary_design, control_design, variables, targets = NULL, type = c("prop", "count"), method = c("rake", "linear", "logit"), algorithm = c("classic_ipf", "nr"), bounds = c(-Inf, Inf), unit_scale = NULL, reference_design = NULL, control = list())`

**Documentation tier:** Tier 3 — Algorithmic. Required `@section` blocks:
`Algorithm`, `Convergence`, `@references`. The existing function already has
these; they must be updated to describe the Opsomer method and the new
`targets` / `type` arguments.

**Signature:**
```r
calibrate_to_survey <- function(
  primary_design,
  control_design,
  variables,
  targets   = NULL,
  type      = c("prop", "count"),
  method    = c("rake", "linear", "logit"),
  algorithm = c("classic_ipf", "nr"),
  bounds    = c(-Inf, Inf),
  unit_scale = NULL,
  reference_design = NULL,
  control = list()
)
```

**Arguments:**

| Argument | Type | Semantics | NULL / default behavior |
|----------|------|-----------|-------------------------|
| `primary_design` | `survey_replicate` or `survey_nonprob` | Design to be calibrated. Must carry replicate weights. | Required; no default |
| `control_design` | `survey_replicate` or `survey_nonprob` | Reference survey providing estimated control totals. Must carry replicate weights. | Required; no default |
| `variables` | tidy-select bare names | Variables in `primary_design@data` for which the control survey provides estimated totals. Must exist in both designs. These are the random (sample-estimated) margins. | Required; no default |
| `targets` | named list or `NULL` | Fixed census margins. Each element's name is a column in `primary_design@data`. Each element is a named numeric vector or a tibble with the variable column plus `"n"` (count) or `"prop"` (proportion). When `NULL`: the Opsomer path runs with `T_fixed = {}` (no fixed margins); `method` and `algorithm` control the calibration procedure. `type` is matched but unused. When non-NULL: the Opsomer path runs with both perturbed random margins and invariant fixed margins. | `NULL` (existing behavior preserved) |
| `type` | character scalar | Controls interpretation of `targets` values: `"prop"` (default) means proportions summing to 1.0 per variable — each element in `targets` must sum to 1.0 or `surveywts_error_targets_totals_invalid` fires; `"count"` means population counts (positive non-NA values). Ignored and produces no error when `targets = NULL`. **Note:** the default `type = "prop"` requires values summing to 1.0; to supply population totals, pass `type = "count"` explicitly. | `"prop"` |
| `method` | character scalar | Calibration method. One of `"rake"` (default), `"linear"`, or `"logit"`. Applies to both the random-margin calibration and the fixed-margin calibration in the Opsomer path. | `"rake"` |
| `algorithm` | character scalar | Raking algorithm; used only when `method = "rake"`. `"classic_ipf"` (default): iterative proportional fitting (Deming & Stephan 1940), the algorithm used in Opsomer & Erciulescu (2022). `"nr"`: Newton-Raphson solver (Deville, Sarndal & Sautory 1993). Silently ignored when `method != "rake"`. | `"classic_ipf"` |
| `bounds` | numeric length 2 | Lower and upper bounds on the calibrated-to-starting-weight ratio. `c(-Inf, Inf)` (default) means no bounds. | `c(-Inf, Inf)` |
| `unit_scale` | numeric vector or `NULL` | Per-unit variance scaling (passed as `variance` to `survey::calibrate()`). Length must equal `nrow(primary_design@data)`. Values must be positive and non-NA. | `NULL` |
| `reference_design` | `survey_taylor` or `NULL` | Stored in history for provenance only; not used in computation. | `NULL` |
| `control` | named list | Calibration tuning parameters. Known keys: `maxit` (default `50L`), `epsilon` (default `1e-7`), `control_col_matches` (not stored in history; see below). Unknown keys trigger `surveywts_warning_control_param_ignored`. `control_col_matches` is an integer vector of length `R` specifying which control replicate maps to which primary replicate. When omitted (the default), a random permutation of `seq_len(min(R, R_C))` is drawn once per call — use `set.seed()` before calling to make results reproducible. The random default satisfies the independence condition of Opsomer & Erciulescu (2022, below eq. 2.10). | `list()` |

**`targets` format (when non-NULL):**

Format A — named list of named numeric vectors (values are proportions summing
to 1.0 per variable, matching the default `type = "prop"`; to supply population
counts, use `type = "count"`):
```r
list(
  age_group = c("18-34" = 0.30, "35-54" = 0.40, "55+" = 0.30),
  region    = c("North" = 0.45, "South" = 0.55)
)
```

Format B — named list of tibbles, each with the variable column plus `"n"` or `"prop"`:
```r
list(
  age_group = tibble(age_group = c("18-34","35-54","55+"), prop = c(0.30, 0.40, 0.30))
)
```

Both formats within the same list are accepted (mixed-format). The function
normalizes all elements to named numeric vectors internally. For Format B
tibbles, the column named `"n"` or `"prop"` is used to identify which column
contains the numeric values (following the same convention as
`calibrate_rake()` and `calibrate_logit()`). The `type` argument governs the
interpretation (count vs. proportion) for **all** elements regardless of
Format B column name — the column name is documentary only.

Variables named in `targets` are calibrated to fixed totals that do not change
across replicates. Variables in `variables` are calibrated to perturbed
control-survey totals that vary per replicate.

**Returns:**

A calibrated design object whose class matches `primary_design`: a
`survey_nonprob` input returns a `survey_nonprob`; a `survey_replicate` input
returns a `survey_replicate`.

Updated full-sample and replicate weights are written back. All replicate weight
columns are updated by the same Opsomer method. A new entry with
`operation = "calibrate_to_survey"` is appended to the weighting history.

History entry parameters when `targets` is non-NULL additionally include:
- `targets` — the fixed margins as supplied by the user (after format normalization to named numeric vectors); when `type = "prop"`, proportions are stored as proportions; when `type = "count"`, counts are stored as counts
- `type` — the `type` argument value
- `fixed_variables` — character vector of variable names from `targets`
- `a_constants` — numeric vector of length `R_eff` (= `K * R`), the `a_s` values for all virtual replicates; when `K = 1`, `R_eff = R` equals the number of primary replicate columns
- `K` — the expansion factor (integer; `1L` when `R_C <= R`)

When `targets = NULL`, the history entry includes `a_constants` and `K` (the Opsomer adjustment constants) but omits `targets`, `type`, and `fixed_variables` (which are undefined when there are no fixed margins).

**Edge cases:**

| Case | Behavior |
|------|----------|
| `targets = NULL` | Opsomer path runs with `T_fixed = {}`. `method` and `algorithm` apply. `type` is matched but unused. `a_constants` and `K` are computed and recorded in history. No call to `svrep::calibrate_to_sample()`. |
| `targets` is supplied, `R > R_C` | Replicates `r = R_C + 1, …, R` use `a_r = 0`, meaning perturbed control totals equal full-sample control totals for those replicates. Calibration still runs for those replicates with unperturbed random margins + fixed margins. |
| `targets` is supplied, `R_C > R` | Expansion factor `K = ceiling(R_C / R)` is computed. Each of the `R` primary replicates is repeated `K` times (total `R_eff = K * R` virtual replicates). The result is collapsed back to `R` primary replicate columns; the `r`-th primary replicate takes the average calibrated weight across its `K` repetitions. `A_eff = A / K` is used for `a_r` computation. The history entry records `K`. |
| `targets` is supplied, `R = R_C` | Standard case: `K = 1`, `A_eff = A`, all `R` replicates have `a_r = sqrt(A_C / A)`. |
| `targets` variable overlaps with `variables` | Not an error. A variable can appear in both. The fixed margin from `targets` applies for that variable; the perturbed total from the control survey for the same variable is not used in calibration (the fixed margin takes precedence for that variable in the combined target set). |
| `targets` has a single variable, one level | Calibration to a single-cell fixed margin. No error. |
| `unit_scale` non-NULL with Opsomer path | `unit_scale` is passed as the `variance` argument to each `survey::calibrate()` call (both full-sample and per-replicate). |
| `type = "prop"`, single-level variable | Proportion of 1.0 is valid (sums to 1). No error. |
| `algorithm` when `method != "rake"` | No error, no warning. `algorithm` is `rlang::arg_match()` matched regardless; its value is not passed to `.calibrate_engine()` when `method` is `"linear"` or `"logit"`. |
| `a_r = 0` replicates (when `R > R_C`) | Perturbed totals equal full-sample totals for those replicates; calibration runs to the same target as the full-sample calibration step. |

**Opsomer algorithm (applies to all calls; `T_fixed = {}` when `targets = NULL`):**

Notation:
- `R` = number of primary replicate columns = `length(primary_design@variables$repweights)`
- `R_C` = number of control replicate columns
- `A` = `primary_design@variables$scale` (scalar replication constant)
- `A_C` = `control_design@variables$scale` (scalar replication constant)
- `t̂_{Cx}` = control full-sample estimated totals for `variables`
- `t̂_{Cx}^(r)` = control replicate-`r` estimated totals for `variables`
- `T_fixed` = fixed population margins from `targets`

Step 1. Extract `A`, `A_C`, `R`, `R_C`.

Step 2. Compute expansion factor:
```
if (R_C > R) {
  K     <- ceiling(R_C / R)
  R_eff <- K * R
  A_eff <- A / K
} else {
  K     <- 1L
  R_eff <- R
  A_eff <- A
}
```

Step 3. Compute `a_r` for `r = 1, …, R_eff`:
```
a_r <- sqrt(A_C / A_eff)   for r = 1, …, min(R_eff, R_C)
a_r <- 0                   for r = min(R_eff, R_C) + 1, …, R_eff
```

Step 4. Compute full-sample control totals `t̂_{Cx}`: for each variable in
`variables`, sum `control_design@data[[v]] * control_full_weights` per level.
Also compute replicate control totals `t̂_{Cx}^(r)` analogously: for each
variable in `variables` and each control replicate `r = 1, …, R_C`, sum
`control_design@data[[v]] * control_design@variables$repweights[[r]]` per
level. (This is the step where `surveywts_error_control_level_missing` is
raised if a level in `primary_design` is absent from `control_design`.)

Step 4b. If `type = "prop"`, convert fixed-margin proportions in `targets` to
population counts. The conversion factor is:
```
N <- sum(primary_design@data[[primary_design@variables$weights]])
```
where `primary_design@variables$weights` is the weight column name as supplied
to this call. `N` is the estimated population size under `primary_design`'s
current weighting scheme — if `primary_design` was produced by a prior
calibration step, this is the post-calibration estimated population size, not
the raw design weight sum. For each variable in `targets`,
`count(level) = proportion(level) × N`. This conversion is performed once;
the resulting count vector is used as the invariant `T_fixed` in Steps 5 and 7.
The conversion is used internally only; the history entry's `targets` field
stores the original normalized user-supplied values (proportions if
`type = "prop"`, counts if `type = "count"`). When `targets = NULL` or
`type = "count"`, this step is skipped and `T_fixed` values are used as supplied.

Step 5. Draw the control replicate mapping. If `control_col_matches` is
provided via `control`, use it directly. Otherwise, draw a random permutation
of `seq_len(min(R_eff, R_C))` once and use it as `control_col_matches` for all
subsequent steps. This single draw is re-used for all replicates in the call.

Step 6. Calibrate full-sample weights of `primary_design` to the combined
target set `{ t̂_{Cx} (for variables NOT in targets), T_fixed (for targets
variables) }` using `.calibrate_engine()` with `method` and `algorithm`. When
a variable appears in both `variables` and `targets`, the fixed margin from
`targets` takes precedence and the perturbed control total for that variable is
excluded from the combined set. This defines `w_i^*` (the calibrated
full-sample weights).

Step 7. For each primary replicate `r = 1, …, R`:
- When `R_C > R`, the `r`-th primary replicate is repeated `K` times; each
  repetition maps to a distinct control replicate `(r-1)*K + 1, …, r*K`.
- For each virtual replicate `s` in the repetitions of primary replicate `r`:
  - For virtual replicates `s > R_C`, `a_s = 0`; no control replicate lookup
    is needed — the perturbed total equals the full-sample total `t̂_{Cx}`
    regardless of `c_s`.
  - For virtual replicates `s <= R_C`, compute perturbed control totals for
    `variables NOT in targets`:
    ```
    t̂*_{Cx}(s) <- t̂_{Cx} + a_s * (t̂_{Cx}^(c_s) - t̂_{Cx})
    ```
    where `c_s` is the mapped control replicate index for virtual replicate `s`
    (from `control_col_matches` determined in Step 5).
  - Starting from the *original* (pre-calibration) primary replicate weights
    `w_i^(r)` — that is, `primary_design@variables$repweights[[r]]` from the
    **input** design, not the calibrated full-sample weights `w_i^*` — calibrate
    to the combined target set `{ t̂*_{Cx}(s) (for variables NOT in targets),
    T_fixed (for targets variables) }` using `.calibrate_engine()` with `method`
    and `algorithm`.
- When `K > 1`, average the `K` calibrated replicate weight vectors to obtain
  the single output replicate weight for primary replicate `r`.

Step 8. Write calibrated full-sample weights and calibrated replicate weights
back into the output design object. Append history entry.

**History entry `parameters` field when `targets` is non-NULL:**

All existing history parameters plus:
- `targets` — the fixed margins as supplied by the user (after format normalization to named numeric vectors); when `type = "prop"`, proportions are stored as proportions; when `type = "count"`, counts are stored as counts
- `type` — character scalar `"count"` or `"prop"`
- `fixed_variables` — character vector of names from `targets`
- `a_constants` — numeric vector of length `R_eff` (= `K * R`), the `a_s` values for all virtual replicates; when `K = 1`, `R_eff = R` equals the number of primary replicate columns
- `K` — integer, the expansion factor (1 when `R_C <= R`)

**Roxygen2 documentation requirements:**

`calibrate_to_survey()` is Tier 3 — Algorithmic. The updated documentation must:

- Update `@description` to note the new capability (mixed fixed + random margins).
- Add `@param targets`, `@param type`, and `@param algorithm`.
- Update `@returns` to note that the history entry always records `a_constants`
  and `K` (Opsomer adjustment constants); when `targets` is non-NULL it
  additionally records `targets`, `type`, and `fixed_variables`.
- `@section Algorithm` — describe the Opsomer perturbation formula using
  `\deqn{}` for the key equations:

  The perturbed control total:
  ```
  \deqn{\hat{t}^*_{Cx}(r) = \hat{t}_{Cx} + a_r \bigl(\hat{t}^{(r)}_{Cx} - \hat{t}_{Cx}\bigr)}
  ```
  The adjustment constant:
  ```
  \deqn{a_r = \begin{cases} \sqrt{A_C / A_{\text{eff}}} & r = 1, \ldots, \min(R_{\text{eff}}, R_C) \\ 0 & r > \min(R_{\text{eff}}, R_C) \end{cases}}
  ```
  where \eqn{A_{\text{eff}} = A / K} when \eqn{R_C > R} (with \eqn{K = \lceil R_C / R \rceil}),
  and \eqn{A_{\text{eff}} = A} otherwise (\eqn{K = 1}). When \eqn{K = 1} this
  reduces to \eqn{\sqrt{A_C / A}}.

  Document the `R_C > R` expansion rule: when the control design has more
  replicates than the primary design, each primary replicate is repeated `K`
  times and calibrated against a distinct subset of control replicates. The
  resulting `K` calibrated weight vectors are averaged to give the single output
  replicate for that primary replicate.

  Add a subsection on calibration method and algorithm choice:
  - When `method = "rake"`, `algorithm` selects between `"classic_ipf"`
    (iterative proportional fitting, Deming & Stephan 1940 — the algorithm
    used by Opsomer & Erciulescu 2022) and `"nr"` (Newton-Raphson raking,
    Deville, Sarndal & Sautory 1993). Both are passed through to
    `.calibrate_engine()`.
  - For `method = "linear"` and `method = "logit"`: Opsomer & Erciulescu (2022)
    §5 note that the method is expected to generalise to other calibration
    estimators of Deville & Särndal (1992), but this is not proven in the
    paper. Use `method = "rake"` with `algorithm = "classic_ipf"` for proven
    behaviour. Prior to this release, `targets = NULL` delegated to
    `svrep::calibrate_to_sample()` which defaulted to `survey::cal.linear()`
    (equivalent to `method = "linear"`); callers who need that prior behavior
    should now supply `method = "linear"` explicitly.

- `@section Convergence` — note that when `targets` is non-NULL, convergence
  failure in any single replicate's `.calibrate_engine()` call raises
  `surveywts_error_calibration_not_converged`. Users may increase `control$maxit`
  or relax `control$epsilon`. Perturbed margins that are inconsistent with fixed
  margins may not converge.

- `@section Warnings` — document the three warning conditions in plain language:
  1. **Unknown control parameters:** Keys in `control` other than `maxit`,
     `epsilon`, and `control_col_matches` are silently ignored with a warning.
     Check the spelling of any custom key before assuming it has an effect.
  2. **Replicate scheme mismatch:** When `primary_design` and `control_design`
     have different replicate types (e.g., bootstrap vs. jackknife), a warning
     is emitted. Results are still returned; the statistical validity of mixing
     replicate schemes is the user's responsibility.
  3. **Negative calibrated weights:** When `method = "linear"` produces negative
     calibrated full-sample weights, those weights are clipped to
     `.Machine$double.eps` and a warning is emitted. This behavior is specific
     to `method = "linear"`; replicate weights are never clipped.

- `@section Limitations` — document two conditions where the method's statistical
  guarantees do not hold:
  1. **Independence assumption:** The Opsomer & Erciulescu (2022) consistency
     proof assumes `primary_design` and `control_design` are independent samples
     from non-overlapping draws. Designs that share respondents (e.g., panel
     waves, subsamples of the control, or any linked-sample design) violate this
     assumption. The function cannot detect overlap; users are responsible for
     verifying the independence condition. Overlapping samples produce variance
     estimates that do not account for the covariance between the two surveys'
     totals.
  2. **Nonprobability samples:** The Opsomer & Erciulescu (2022) consistency
     proof assumes probability samples with design-based replicate variance. When
     `survey_nonprob` designs are supplied, the method operates mechanically but
     the variance interpretation depends on how the replicate weights were
     constructed.

- `@references` — add Opsomer & Erciulescu (2022):

## Quality gates

- When `targets = NULL` and `method = "linear"`, calibrated full-sample and
  replicate weights must match `svrep::calibrate_to_sample()` within 1e-8
  (validated in the test-spec numerical oracle section).
- When `targets = NULL` and `method = "rake"` (default), calibrated full-sample
  weights must satisfy the full-sample control-survey totals `t̂_{Cx}` within
  `control$epsilon`.
- When `targets` is non-NULL and `A` or `A_C` is NULL on either design,
  `surveywts_error_scale_not_found` is raised before any calibration is attempted.
- Calibrated full-sample weights from the Opsomer path must satisfy the fixed
  `targets` margins exactly (within raking convergence tolerance `control$epsilon`).
- Calibrated full-sample weights must satisfy the full-sample control totals
  `t̂_{Cx}` for the `variables` margins.
- All replicate weights written to the output design must be numeric; negative
  replicate weights are expected and must NOT be clipped. Only full-sample
  negative weights trigger `surveywts_warning_negative_calibrated_weights`
  (existing behavior for `method = "linear"`).
- The output object class matches `primary_design` class (existing invariant,
  unchanged).
- The weighting history entry grows by exactly 1 per call.
- `control_col_matches` is never stored in the history entry (existing behavior,
  unchanged).
- `type` argument is `rlang::arg_match()` matched (applies whether `targets`
  is NULL or not).
- `algorithm` argument is `rlang::arg_match()` matched (applies whether
  `method = "rake"` or not). When `method != "rake"`, the matched value is
  not passed to `.calibrate_engine()`.
