# Spec — jackknife-merge

**Status**: SPEC_READY → DRAFT
**Target version**: 0.7.0.9000
**PR range**: PR 1–2

---

## Scope

### In

- Replace the existing `create_jackknife_weights()` (delete-1/random-groups
  interface) with a unified function accepting `type = c("jkn", "jk1",
  "grouped")`.
- Move all DAGJK engine internals from `create_group_jackknife_weights.R`
  into the merged implementation file (renamed `jackknife-dagjk-utils.R`).
- Delete `create_group_jackknife_weights.R` (no deprecation wrapper).
- Remove `"group-jackknife"` from `create_replicate_weights()` dispatcher.
- Register all new/renamed error and warning classes in
  `plans/error-messages.md` (done ahead of this spec).

### Out

- No change to `create_bootstrap_weights()`, `create_brr_weights()`,
  `create_sdr_weights()`, `create_gen_boot_weights()`,
  `create_gen_rep_weights()`, or `as_taylor_design()`.
- No change to `replicate-utils.R` shared helpers
  (`.validate_replicate_input()`, `.validate_replicates_arg()`,
  `.snapshot_variables_for_history()`, `.convert_and_call()`,
  `.validate_reference_sample()`, `.handle_repweights_overwrite()`,
  `.dispatch_calibration_replay()`, `.reestimate_margins_from_reference()`,
  `.extract_weight_vec()`).
- No new exported function; `create_group_jackknife_weights()` is deleted,
  not deprecated.
- No new S7 class or property.

## Function contracts

### `create_jackknife_weights(data, replicates = NULL, ..., type = c("jkn", "jk1", "grouped"), mse = TRUE, var_strat = NULL, var_strat_frac = NULL, sort_var = NULL, adj_method = c("variance-stratum-psus", "variance-units"), scale_method = c("variance-stratum-psus", "variance-units"), reference_sample = NULL, seed = NULL)`

**Documentation tier:** Tier 3 — Algorithmic

**Dispatch table:**

| `type` | Input class | Backend |
|--------|-------------|---------|
| `"jkn"` | `survey_taylor` | `survey::as.svrepdesign(type = "JKn", mse = mse)` via `.convert_and_call()` |
| `"jk1"` | `survey_taylor` | `survey::as.svrepdesign(type = "JK1", mse = mse)` via `.convert_and_call()` |
| `"grouped"` | `survey_taylor` | `svrep::as_random_group_jackknife_design(replicates = replicates, mse = mse, var_strat = var_strat, var_strat_frac = var_strat_frac, sort_var = sort_var, adj_method = adj_method, scale_method = scale_method)` via `.convert_and_call()` |
| `"grouped"` | `survey_nonprob` | DAGJK engine: `.dagjk_single_replicate()` (IPW path) or `.dagjk_single_replicate_calib()` (calibration-only path) |

#### Signature

```r
create_jackknife_weights <- function(
  data,
  replicates = NULL,
  ...,
  type = c("jkn", "jk1", "grouped"),
  mse = TRUE,
  var_strat = NULL,
  var_strat_frac = NULL,
  sort_var = NULL,
  adj_method = c("variance-stratum-psus", "variance-units"),
  scale_method = c("variance-stratum-psus", "variance-units"),
  reference_sample = NULL,
  seed = NULL
)
```

---

#### Arguments

**`data`**
- Type: `survey_taylor` or `survey_nonprob`
- `data.frame`, `weighted_df`, and `survey_replicate` inputs all error.
- `survey_nonprob` is only valid when `type = "grouped"`.

**`replicates`**
- Type: `integer(1)` or `NULL`
- Default: `NULL`
- Purpose depends on `type`:
  - `"jkn"`, `"jk1"`: silently ignored. These types are deterministic; the
    replicate count is derived from the PSU structure.
  - `"grouped"` + `survey_taylor`: required — errors if `NULL`. Number of
    random groups passed to `svrep::as_random_group_jackknife_design()`.
  - `"grouped"` + `survey_nonprob`: required — errors if `NULL`. Number of
    DAGJK deletion groups G. Must be a whole number >= 2. Whole-number doubles
    (e.g., `50.0`) are coerced to integer. Must not exceed the combined
    NPS + reference row count. Documentation should advise that `G = 50` is a
    practical starting point (Valliant, Dever & Kreuter 2018 Table 15.2:
    >= 50 degrees of freedom for CV(SE) <= 10%; Valliant 2020 used G = 50
    in simulation).
- **Intentional design:** unlike `create_group_jackknife_weights()` which had
  `groups = 50L` as a default, `replicates` has no built-in default. Callers
  must always supply a value when `type = "grouped"`. This is documented in
  `plans/jackknife-merge-decisions.md §Argument Decisions § replicates` and is
  a deliberate breaking change.
- Validation for the DAGJK path uses a renamed internal helper
  `.validate_replicates_dagjk_arg()` (see DAGJK internals section). Validation
  for the `survey_taylor` grouped path uses the existing
  `.validate_replicates_arg()`.

**`...`**
- Must be empty. `rlang::check_dots_empty()` is called on every path.

**`type`**
- Type: `character(1)`
- Default (first value): `"jkn"`
- Matched via `rlang::arg_match(type)`.
- `"jkn"`: stratified delete-one jackknife. One replicate per PSU across all
  strata. Valid for `survey_taylor` only.
- `"jk1"`: unstratified delete-one jackknife. One replicate per unit, ignoring
  stratification. Valid for `survey_taylor` only. Documentation must note that
  JK1 ignores stratification and will generally overestimate variance when
  applied to a multi-stratum design.
- `"grouped"`: random-group jackknife. Valid for both `survey_taylor` (routes
  to svrep) and `survey_nonprob` (routes to DAGJK engine).

**`mse`**
- Type: `logical(1)`
- Default: `TRUE`
- `"jkn"`, `"jk1"`, `"grouped"` + `survey_taylor`: passed through to the
  backend. `TRUE` centers each replicate deviation on the full-sample estimate
  (Wolter 2007 v_4 form; conservative). `FALSE` centers on the within-stratum
  mean of replicate estimates (v_1 form).
- `"grouped"` + `survey_nonprob` (DAGJK): user-supplied value is checked. If
  `mse = FALSE`, emit `surveywts_warning_jackknife_mse_overridden` and override
  to `TRUE` before proceeding. The DAGJK variance formula
  `v_J = ((G-1)/G) * sum((theta_g - theta)^2)` centers on the full-sample
  estimate `theta`; `mse = FALSE` is not consistent with the published formula
  (Kott 2001 eq. 1; Wolter 2007 §4.5).

**`var_strat`**
- Type: `character(1)` or `NULL`
- Default: `NULL`
- Applicable to `"grouped"` + `survey_taylor` only; passed to
  `svrep::as_random_group_jackknife_design()`.
- Silently ignored for `"jkn"` and `"jk1"`.
- For `"grouped"` + `survey_nonprob`: if non-`NULL`, emit
  `surveywts_warning_jackknife_svrep_args_ignored` and ignore. The warning
  is emitted once for all non-default svrep arguments collectively (not once
  per argument).

**`var_strat_frac`**
- Type: `numeric(1)` or `NULL`
- Default: `NULL`
- Same applicability and ignored-path behavior as `var_strat`.

**`sort_var`**
- Type: `character(1)` or `NULL`
- Default: `NULL`
- Same applicability and ignored-path behavior as `var_strat`.
- Not applicable to DAGJK because: (1) DAGJK uses its own `sample()` engine,
  not svrep; (2) DAGJK groups span the combined NPS + reference sample making
  a single sort variable non-trivial; (3) sorted group assignment is not
  described in the DAGJK literature.

**`adj_method`**
- Type: `character(1)`
- Default (first value): `"variance-stratum-psus"` (matches svrep default)
- Choices: `"variance-stratum-psus"`, `"variance-units"`
- Applicable to `"grouped"` + `survey_taylor` only; passed to
  `svrep::as_random_group_jackknife_design()`.
- Silently ignored for `"jkn"` and `"jk1"`.
- For `"grouped"` + `survey_nonprob`: if value differs from the default
  `"variance-stratum-psus"`, emit `surveywts_warning_jackknife_svrep_args_ignored`
  and ignore. The warning is emitted once for all non-default svrep arguments
  collectively.

**`scale_method`**
- Type: `character(1)`
- Default (first value): `"variance-stratum-psus"` (matches svrep default)
- Choices: `"variance-stratum-psus"`, `"variance-units"`
- Same applicability and ignored-path behavior as `adj_method`.

**`reference_sample`**
- Type: `survey_taylor` or `NULL`
- Default: `NULL`
- Only meaningful for `"grouped"` + `survey_nonprob` (DAGJK path).
- When non-`NULL`, overrides any reference design stored in the `ipw()`
  history entry (silent precedence, consistent with existing DAGJK behavior).
- When non-`NULL` and not a `survey_taylor`, errors with
  `surveywts_error_reference_sample_class` (existing error class, same behavior
  as `.validate_reference_sample()`).
- When supplied alongside `"jkn"`, `"jk1"`, or `"grouped"` + `survey_taylor`:
  `reference_sample` is documented as DAGJK-only; no runtime warning is emitted
  when it is supplied but unused on those paths (it is simply silently ignored).

**`seed`**
- Type: `integer(1)` or `NULL`
- Default: `NULL`
- Meaningful only for `type = "grouped"` (both input classes): controls RNG
  for random group assignment.
- `"jkn"` and `"jk1"`: deterministic; silently ignored.
- For `"grouped"` + `survey_taylor`: passed to `.convert_and_call()` which
  calls `withr::local_seed(seed)` before invoking the svrep backend.
- For `"grouped"` + `survey_nonprob` (DAGJK): `set.seed(seed)` is called once
  immediately before group assignment. The global RNG state is not restored.

---

#### Returns

**`"jkn"`, `"jk1"`, `"grouped"` + `survey_taylor`:** A `survey_replicate`
with:
- Replicate weight columns in `@data` named `rep_1`, `rep_2`, ..., `rep_R`.
- `@variables$repweights` populated with those column names.
- `@variables$type` set to `"JKn"` (for `"jkn"`), `"JK1"` (for `"jk1"`), or
  `"random-group"` (for `"grouped"` + `survey_taylor`, as returned by svrep).
- `@variables$scale`, `@variables$rscales`, `@variables$mse` populated from
  the svrep/survey backend output.
- `@metadata@weighting_history` has one new entry appended with
  `operation = "replicate_creation"`, `method = "jackknife"`, and
  `parameters$type` recording the variant string (`"jkn"`, `"jk1"`, or `"grouped"`).

**`"grouped"` + `survey_nonprob`:** A `survey_nonprob` with:
- G_success replicate weight columns added to `@data`, named `repwt_1`,
  `repwt_2`, ..., `repwt_{G_success}`.
- `@variables$repweights` populated with those column names.
- `@variables$type` set to `"group-jackknife"` (unchanged from current DAGJK).
- `@variables$scale` set to `(G_success - 1) / G_success`.
- `@variables$rscales` set to `rep(1, G_success)`.
- `@variables$mse` set to `TRUE`.
- `@metadata@weighting_history` has one new entry appended with
  `operation = "jackknife_weights"` and `parameters$type = "grouped"`.

#### Edge cases

| Case | Behavior |
|------|----------|
| `replicates = NULL`, `type = "jkn"` | `replicates` is silently ignored; no error |
| `replicates = NULL`, `type = "jk1"` | `replicates` is silently ignored; no error |
| `replicates = 50.0`, `type = "grouped"`, `survey_nonprob` | Coerced to `50L`; no error |
| `seed = NULL` | No seed set; non-reproducible group assignment for DAGJK; `.convert_and_call()` does not call `withr::local_seed()` |
| `seed = 42`, `type = "jkn"` | `seed` silently ignored; function is deterministic |
| `mse = FALSE`, `type = "grouped"`, `survey_nonprob` | Warning emitted; `mse` overridden to `TRUE` |
| `var_strat = "region"`, `type = "grouped"`, `survey_nonprob` | Warning emitted; `var_strat` ignored |
| `adj_method = "variance-units"`, `type = "grouped"`, `survey_nonprob` | Warning emitted (non-default value detected); ignored |
| `adj_method = "variance-stratum-psus"`, `type = "grouped"`, `survey_nonprob` | Default value; no warning |
| `reference_sample` supplied with `type = "jkn"` | `reference_sample` silently ignored (documented as DAGJK-only) |
| `type = "grouped"`, `survey_nonprob`, history contains both IPW and calibration entries | Routes to IPW path (doubly-robust); `ipw_entry` takes precedence |
| `type = "grouped"`, `survey_nonprob`, calibration-only Level A (no reference needed) | Level A detected via `isTRUE(calib_entry$parameters$targets_from_reference) == FALSE`; `ref_design = NULL`; `combined_n = n_nps` |
| `type = "grouped"`, `survey_nonprob`, 0 rows in NPS | Caught by `.validate_replicate_input()` upstream |
| All DAGJK replicates fail | `surveywts_error_jackknife_all_replicates_failed`; function aborts |
| More than 10% DAGJK replicates fail but not all | `surveywts_warning_jackknife_replicates_failed`; function returns with `G_success` successful replicates; scale adjusted to `(G_success - 1) / G_success` |
| `type = "grouped"`, `survey_nonprob`, `replicates = 1` | `surveywts_error_jackknife_replicates_too_small` |
| `type = "grouped"`, `survey_nonprob`, `replicates` > combined row count | `surveywts_error_jackknife_replicates_exceeds_n` (checked after reference resolution) |

## Input validation order

The following order is enforced for all `type` / input class combinations.
Steps 1–4 apply on every call. Steps 5–15 apply only on the DAGJK path
(`type = "grouped"` + `survey_nonprob`).

1. `rlang::check_dots_empty()` — `...` must be empty.
2. `.validate_replicate_input(data)` — rejects `data.frame`, `weighted_df`,
   `survey_replicate`, and unsupported classes.
3. `type <- rlang::arg_match(type)` — resolves the type string.
4. **Type/class incompatibility check:** if `data` is `survey_nonprob` and
   `type %in% c("jkn", "jk1")`, error
   `surveywts_error_jackknife_type_nonprob_only`.
5. **`reference_sample` class check** (if non-`NULL`): call
   `.validate_reference_sample(reference_sample)`.
6. **`replicates` required check:** if `type = "grouped"` and
   `replicates = NULL`, error `surveywts_error_jackknife_replicates_required`.
7. **`replicates` value check (Phase 1, no ceiling):** call
   `.validate_replicates_dagjk_arg(replicates, combined_n = Inf)` — validates
   type, whole-number property, and minimum (>= 2).
8. **History routing:** scan `data@metadata@weighting_history` for `ipw`
   entries and the last calibration entry. If neither found, error
   `surveywts_error_jackknife_no_history`.
9. **Level detection:** `use_level_b <- isTRUE(calib_entry$parameters$targets_from_reference)`.
10. **Reference resolution (conditional):**
    - IPW path: resolve `ref_design <- reference_sample %||% ipw_entry$reference_design`; if `NULL`, error `surveywts_error_jackknife_no_reference`. Set `n_ref`, `combined_n`.
    - Calibration-only Level B: resolve from calibration history entry; if `NULL`, error `surveywts_error_jackknife_no_reference`. Set `n_ref`, `combined_n`.
    - Calibration-only Level A: `ref_design = NULL`, `n_ref = 0L`, `combined_n = n_nps`.
11. **`replicates` ceiling check (Phase 2):** call
    `.validate_replicates_dagjk_arg(replicates, combined_n = combined_n)`.
12. **`mse` check:** if `mse = FALSE`, emit
    `surveywts_warning_jackknife_mse_overridden`, set `mse <- TRUE`.
13. **svrep args check (for `survey_nonprob`):** if any of `var_strat`,
    `var_strat_frac`, `sort_var` is non-`NULL`, or `adj_method` /
    `scale_method` is not at its default value, emit
    `surveywts_warning_jackknife_svrep_args_ignored` once.
14. **Overwrite check:** call `.handle_repweights_overwrite()` with
    `warning_class = "surveywts_warning_jackknife_repweights_overwritten"`.
15. **Small groups warning:** if `floor(combined_n / replicates) < 5`, emit
    `surveywts_warning_jackknife_small_groups`.

Note: Steps 12–13 are ordered after reference resolution (step 10) to avoid
spurious svrep-args warnings on error paths.

- `data`: `survey_taylor`

### Grouped + `survey_nonprob` path (DAGJK engine)

The DAGJK engine runs entirely within `create_jackknife_weights()` and the
helpers in `jackknife-dagjk-utils.R`. The engine:

1. Validates and resolves inputs (steps 5–15 of validation order above).
2. Calls `.handle_repweights_overwrite()` to clear any existing replicate weights.
3. Emits `surveywts_warning_jackknife_small_groups` if average group size < 5.
4. Calls `set.seed(seed)` if `seed` is non-`NULL`.
5. Assigns `combined_n` rows to `replicates` groups via `sample(rep(seq_len(replicates), length.out = combined_n))`.
6. Loops over `g = 1, ..., replicates`: calls `.dagjk_single_replicate()` (IPW path) or `.dagjk_single_replicate_calib()` (calibration-only path) inside `tryCatch()`; counts failures.
7. After the loop: emits `surveywts_warning_jackknife_replicates_failed` if `failed_reps > 0.1 * replicates`; errors `surveywts_error_jackknife_all_replicates_failed` if `G_success == 0L`.
8. Assembles `repwt_1` through `repwt_{G_success}` columns in `@data`.
9. Emits `surveywts_warning_jackknife_negative_replicate_weights` if any value in the replicate matrix is < 0.
10. Sets `@variables$repweights`, `@variables$scale`, `@variables$rscales`, `@variables$mse`, `@variables$type`.
11. Appends history entry to `@metadata@weighting_history`.

### Modified helpers

**`.dagjk_single_replicate()`** — Extended formula added (Kott 2001 §3 eq. 2).

The existing function applies the standard zero-and-rescale weight rule to all rows:
`w_{k(g)} = 0` (group g) or `n_h / (n_h - n_hg) * w_k` (otherwise), where `n_h`
and `n_hg` are computed per design stratum. When `n_h < G` for any stratum h, the
standard formula is upward-biased. The updated function dispatches per stratum:

**Stratum-level dispatch:**
- If `n_hg == 0` (no rows from stratum h in group g): weights unchanged (`w_k`)
- If `n_h >= G` (or `n_h > n_hg`, standard condition): apply standard formula
  `n_h / (n_h - n_hg) * w_k` (retained rows), `0` (deleted rows)
- If `n_h < G` (extended formula applies, Kott 2001 §3 eq. 2):
  - Compute `Z = sqrt(G / ((G - 1) * n_h * (n_h - 1)))`
  - Rows whose PSU is in group g: `w_k * (1 - (n_h - 1) * Z)`
  - Rows in stratum h but PSU not in group g: `w_k * (1 + Z)`
  - Rows not in stratum h: `w_k` (unchanged)

**Boundary continuity:** When `n_h == G`, Z = 1/(n_h - 1) and the extended formula
reduces to the standard formula (verified analytically in Kott 2001 §3).

**Negative weight trap when `n_h = 2`:** Because `sqrt(G/(G-1)) > 1` for all finite
G, the deleted-PSU multiplier `1 - (n_h - 1)*Z = 1 - sqrt(G/(G-1))` is always
negative when `n_h = 2`. This is a known limitation of the extended formula (Kott 2001
§3 does not address it). The function does not error; the negative weights propagate
through the replicate and are caught by `surveywts_warning_jackknife_negative_replicate_weights`
after the replicate loop.

**Degenerate check:** The degenerate replicate condition is expanded from
"non-positive or NA weights" to "non-positive, non-finite, or NA weights." Inf weights
(arising from `n_h / (n_h - n_hg)` when `n_hg = n_h`, i.e., all PSUs from a stratum
fall in one group) are counted as failures. This covers gotcha 7 from `comprehension.md`.

**Stratum variable for NPS:** For `survey_nonprob` inputs with no explicit stratum
variable, all rows form one stratum with `n_h = n_nps`. The condition `n_h < G`
requires `n_nps < G`, which is prevented by `surveywts_error_jackknife_replicates_exceeds_n`.
The extended formula is therefore unreachable in the one-stratum NPS case. If the NPS
data has an explicit stratum variable in `@variables$strata`, per-stratum dispatch
applies and the extended formula may fire for small strata.

**`.dagjk_single_replicate_calib()`** — Degenerate check updated from "non-positive
or NA" to "non-positive, non-finite, or NA" (same Inf weight fix as above).

Generates jackknife replicate weights for probability and non-probability
survey designs. For probability samples (`survey_taylor`), supports the

### Algorithm section content

Use `**Bold sub-headers**` per algorithm variant within the `@section Algorithm:` block.

**JKn (stratified delete-one jackknife)**

State that one replicate is constructed per PSU across all strata by setting
the deleted PSU's units to weight zero and rescaling remaining units in the
same stratum. Give the weight rule as a display equation:

```
\deqn{
  w_{k(hi)} = \begin{cases}
    0 & \text{if unit } k \text{ is in PSU } i \text{ of stratum } h \\
    \frac{n_h}{n_h - 1}\, w_k & \text{if unit } k \text{ is in stratum } h,\; k \neq i \\
    w_k & \text{otherwise}
  \end{cases}
}
```

Give the variance estimator for `mse = TRUE` (v_4 form, Wolter 2007 eq. 4.6.4a;
default and conservative):

```
\deqn{
  v_J(\hat\theta) = \sum_{h=1}^{H} \frac{n_h - 1}{n_h}
    \sum_{i=1}^{n_h} (\hat\theta_{(hi)} - \hat\theta)^2
}
```

And for `mse = FALSE` (v_1 form, Wolter 2007 §4.5; centers on within-stratum mean):

```
\deqn{
  v_1(\hat\theta) = \sum_{h=1}^{H} \frac{n_h - 1}{n_h}
    \sum_{i=1}^{n_h} (\hat\theta_{(hi)} - \bar\theta_{(h\cdot)})^2
}
```

where `\eqn{\bar\theta_{(h\cdot)} = \frac{1}{n_h} \sum_{i=1}^{n_h} \hat\theta_{(hi)}}`
is the within-stratum mean of replicate estimates. Both forms are unbiased to
second-order moments (Wolter 2007 Theorem 4.5.3); `mse = TRUE` is more conservative.

Note that total replicates = sum of PSU counts across strata.
Delegated to `survey::as.svrepdesign(type = "JKn")`.

**JK1 (unstratified delete-one jackknife)**

State that JK1 is a special case of JKn with a single stratum spanning all
units. Scale factor `(n-1)/n`. Total replicates = n.

```
\deqn{
  v_J(\hat\theta) = \frac{n-1}{n} \sum_{i=1}^{n} (\hat\theta_{(i)} - \hat\theta)^2
}
```

Note that JK1 ignores stratification and will overestimate variance for
multi-stratum designs. Delegated to
`survey::as.svrepdesign(type = "JK1")`.

**Grouped jackknife (probability samples)**

State that PSUs are divided into G random groups; the g-th replicate drops all
PSUs in group g and rescales remaining PSUs. Variance estimator per Valliant,
Dever & Kreuter (2018) eq. 15.16. Delegated to
`svrep::as_random_group_jackknife_design()`.

**Delete-a-group jackknife for non-probability samples (DAGJK)**

State that for non-probability samples without PSU structure, each row is
treated as its own unit and randomly assigned to one of G deletion groups.
The full estimation pipeline — IPW propensity fitting and/or calibration — is
replayed within each replicate on the reduced (leave-group-out) dataset.
Replicate weight construction rule (Kott 2001 eq. 1):

```
\deqn{
  w_{k(g)} = \begin{cases}
    0 & \text{if unit } k \text{ is in group } g \\
    \dfrac{n_h}{n_h - n_{hg}}\, w_k & \text{otherwise}
  \end{cases}
}
```

where `n_h` = PSUs in design stratum `h` and `n_hg` = PSUs from stratum `h`
in group `g`. This is the standard formula; it applies when `n_h >= G` for stratum h.

When `n_h < G` for a stratum (fewer PSUs than groups), the standard formula
is upward-biased. The extended formula (Kott 2001 §3 eq. 2) applies per stratum:

```
\deqn{
  w_{k(g)}^{(E)} = \begin{cases}
    w_k & \text{if no PSU from stratum } h \text{ is in group } g \\
    w_k \bigl(1 - (n_h - 1)\, Z\bigr) & \text{if PSU containing } k \text{ is in group } g \\
    w_k (1 + Z) & \text{if PSU in stratum } h,\; \text{not in group } g
  \end{cases}
}
```

where `Z = sqrt(G / ((G - 1) * n_h * (n_h - 1)))`. When `n_h = 2`, the
deleted-PSU multiplier `1 - Z` is always negative (a known limitation; the
resulting negative weights trigger `surveywts_warning_jackknife_negative_replicate_weights`).
For `survey_nonprob` inputs with no explicit stratum variable, `n_h = n_nps`
and `n_h < G` cannot arise (prevented by `surveywts_error_jackknife_replicates_exceeds_n`).

Variance estimator (Kott 2001 eq. 1; Valliant 2020 eq. 3):

```
\deqn{
  v_J(\hat\theta) = \frac{G - 1}{G}
    \sum_{g=1}^{G} (\hat\theta_{(g)} - \hat\theta)^2
}
```

The centering point `hat_theta` is the full-sample estimate; centering on the
mean of replicate estimates is not consistent with this formula and is not
accepted (`mse = FALSE` is overridden to `TRUE` with a warning). Scale factor
is adjusted to `(G_success - 1) / G_success` when some replicates fail.

### Limitations section

Include a `@section Limitations:` block noting:
1. Jackknife variance estimation is not consistent for quantiles and other
   non-smooth statistics (Wolter 2007 §4.2.4; Valliant, Dever & Kreuter 2018
   §15.4.1; Elliott & Valliant 2017 §4.1). Use the bootstrap for quantile
   variance.
2. JK1 will generally overestimate variance for multi-stratum designs because
   it ignores stratification.
3. JKn and JK1 assume negligible finite population correction (WR or near-WR
   first-stage sampling, Wolter 2007 §4.3.3). For designs with substantial
   sampling fractions, jackknife variance estimates are positively biased; set
   `fpc =` in the design object to enable FPC-adjusted estimation or consider BRR.
4. For the DAGJK path, pseudo-weights and their variance estimates may be
   biased when the inclusion mechanism is non-ignorable (NMAR). DAGJK cannot
   detect or correct NMAR.
5. The DAGJK assumes negligible finite population correction. When the
   non-probability sample is a large fraction of the finite population, DAGJK
   variance estimates are positively biased.

### Warnings section

Include a `@section Warnings:` block documenting:
1. When `mse = FALSE` is passed with `type = "grouped"` for a
   non-probability sample, the argument is overridden to `TRUE`. The DAGJK
   variance formula requires centering on the full-sample estimate.
2. When `var_strat`, `var_strat_frac`, `sort_var`, `adj_method`, or
   `scale_method` are set to non-default values for a non-probability sample
   with `type = "grouped"`, these arguments are ignored. They apply only to
   the grouped jackknife for probability samples.
3. If more than 10% of group replicates fail, a warning reports the count.
   Consider reducing `replicates` or checking for extreme covariate imbalance.
