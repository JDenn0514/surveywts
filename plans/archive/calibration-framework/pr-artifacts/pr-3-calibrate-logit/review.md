The `.make_calfun_logit()` formula matches the spec exactly:
- `A = (U - L) / ((1 - L) * (U - 1))` — confirmed.
- `F(u) = (L(U-1) + U(1-L)exp(Au)) / (U - 1 + (1-L)exp(Au))` — confirmed.
- `F'(u) = A * (F(u) - L) * (U - F(u)) / (U - L)` — confirmed.

The `.build_calibration_provenance()` fallback for `lambda` (line 231: when `lambda` is NULL and `method == "logit"`, uses `crossproduct_inv %*% discrepancy`) is not reachable from `calibrate_logit()` because the function always passes `lambda = engine_result$lambda` explicitly. The fallback is an artifact of backward-compatibility code; it does not affect the logit path.

Comprehension alignment: clean for all gotchas except H7 (reference_design history flag — see Step 1).
