# surveywts Code Style Guide

**Version:** 1.1
**Status:** Decided — do not re-litigate without updating this document

## Quick Reference

| Decision | Choice |
|----------|--------|
| Indentation | 2 spaces |
| Line length | 80 characters |
| Auto-formatter | `air` (Posit's R formatter) |
| Pipe operator | Native `\|>` only |
| Style guide | tidyverse style (via air) |
| Property access | Direct `@` everywhere on surveycore S7 objects — no accessor functions defined in surveywts |
| Argument order | `x`/`data` first → required NSE → required scalar → optional NSE → optional scalar → `...` |
| Internal helper placement | Inline if used in 1 file; shared utils file if used in 2+ files |
| Dispatch rule | `S7::method()` for extending existing generics; plain function + `S7::S7_inherits()` for surveywts-owned generics |
| Type check (S7 objects) | `S7::S7_inherits(x, surveycore::survey_taylor)` — fully qualified, never a string |
| Type check (weighted_df) | `inherits(x, "weighted_df")` — bare `inherits()` for the S3 class |
| Print method file | `methods-print.R`; registered via `S7::methods_register()` in `.onLoad()` |
| Weighting function returns | Visible (updated object, same class as input) |
| Diagnostic function returns | Visible (named scalar or tibble) |
| Print/summary methods | `invisible(x)` |
| Validators (internal) | `invisible(TRUE)` on success |
| Error structure | `"x"` + `"i"` + optional `"v"` bullets; `class=` on every `cli_abort()` |
| Warning classes | `class=` on every `cli_warn()` too |
| Message language | Declarative for `"x"`/`"i"` bullets; imperative for `"v"` bullet |
| Import style | `::` everywhere; no `@importFrom` in any source file |
| NAMESPACE edits | Never manual — 100% generated by `devtools::document()` |
| `R CMD check` | 0 errors, 0 warnings, ≤2 pre-approved notes |

## General R style

- `<-` for all assignments; `=` only for function arguments.
- Native `\|>` only — `%>%` is never used.
- Run `air format .` before opening a PR; reformat-only commits stay separate
  from functional changes. Config lives in `air.toml` and `.editorconfig` in
  the package root — read them there, not here.

## Working with S7 objects

- Use `@` directly everywhere to access properties of surveycore S7 objects
  in internal code — surveywts defines no accessor functions.
- Print methods for surveycore classes (`survey_nonprob`, `survey_replicate`)
  live in `R/methods-print.R`, registered via `S7::methods_register()` from
  `.onLoad()` in `R/zzz.R`.
- Class membership: always `S7::S7_inherits(x, ClassObject)` with the class
  object, fully qualified when the class comes from surveycore — never a
  string and never bare `inherits()`.
- `weighted_df` is surveywts's only home-grown class — an S3 subclass of
  tibble, class vector `c("weighted_df", "tbl_df", "tbl", "data.frame")`.
  Test it with base `inherits(x, "weighted_df")`, never `S7::S7_inherits()`.
  Its attributes are `weight_col` (character scalar) and `weighting_history`
  (list). Users never construct it directly — build one internally with
  `.make_weighted_df()` from `utils.R`.
- Every weighting function accepts `data.frame`, `weighted_df`, and S7 survey
  objects. Dispatch order: check `S7::S7_inherits(data, surveycore::survey_nonprob)`
  first, then `inherits(data, "weighted_df")`, then plain data.frame — check
  S7 objects before `weighted_df` because `survey_nonprob` inherits from
  `data.frame` and would pass an `is.data.frame()` check if tested last.
  Each path appends the same history-entry shape (`step`, `timestamp`,
  `operation`, plus function-specific fields) to
  `attr(result, "weighting_history")` or `result@metadata@weighting_history`.

## Errors and warnings

Standard structure — `class=` is required on EVERY `cli_abort()` and
`cli_warn()` call, no exceptions:

```r
cli::cli_abort(
  c(
    "x" = "What went wrong (declarative).",      # always present
    "i" = "Context or diagnosis.",                # usually present
    "v" = "How to fix it (imperative)."           # when fixable
  ),
  class = "surveywts_error_{condition}"
)
```

- Class naming: `surveywts_error_{snake_case_condition}` /
  `surveywts_warning_{snake_case_condition}`.
- The canonical class list is `plans/error-messages.md`. Adding a new error:
  add the table row there first, use that class in code, add an
  `expect_error(class = ...)` test.
- Register: `"x"` declarative with the object as subject; `"i"` declarative
  with the system as subject; `"v"` imperative. Never address the user
  ("You must...").

### cli inline markup

| Showing | Markup | Renders as |
|---------|--------|------------|
| Function argument | `{.arg weights}` | `weights` |
| Column / variable name | `{.field {var}}` | `var` |
| Function name | `{.fn as_survey}` | `as_survey()` |
| Code snippet | `{.code nest = TRUE}` | `nest = TRUE` |
| A value | `{.val "brr"}` | `"brr"` |
| A class name | `{.cls survey_taylor}` | `<survey_taylor>` |

## Function design

Return visibility:

| Function type | Return |
|---------------|--------|
| Calibration / nonresponse / utility functions | Visible (updated object, same class as input) |
| Diagnostic functions | Visible (named scalar or tibble) |
| `ipw()` | Visible (always `survey_nonprob`, regardless of input class) |
| Print methods | `invisible(x)` |
| Internal validators (`.validate_*()`) | `invisible(TRUE)` on success |
| Internal constructors (`.new_*()`, `.make_weighted_df()`) | Visible (the new object) |

Argument order precedence:

1. `x` / `data` — the survey object or data frame, always mandatory, first
2. Required NSE/tidy-select arguments
3. Required scalar arguments
4. Optional NSE/tidy-select arguments (`weights = NULL`, ...)
5. Optional scalar control arguments (`nest = FALSE`, `mse = TRUE`, ...)
6. `...`

Dispatch — surveywts functions are plain R functions, never S7 or S3
generics. Type dispatch is always explicit:

| Situation | Use |
|-----------|-----|
| Type checking a surveycore S7 object | `S7::S7_inherits(x, surveycore::survey_nonprob)` |
| Type checking `weighted_df` | `inherits(x, "weighted_df")` |
| Registering a print method for a surveycore class | `S7::method(print, surveycore::survey_nonprob) <- function(x, ...) { }` in `methods-print.R` |

**Never use `UseMethod()` — S3 dispatch does not work for S7 objects.**

Internal helpers: not exported, `.`-prefixed.

| Helper used in... | Lives in... |
|-------------------|-------------|
| Exactly 1 source file | Inline, below the exported function |
| 2+ functions in the same family | `{family}-utils.R` |
| 2+ functions across different families | `utils.R` |
