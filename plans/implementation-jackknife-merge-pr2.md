## Summary

- Replaced `create_jackknife_weights()` with a unified implementation that handles
  JKn, JK1 (probability-sample delete-one), grouped jackknife for probability samples
  (via `svrep`), and DAGJK for non-probability samples — all via a `type` argument.
- Deleted `create_group_jackknife_weights()` and removed the `"group-jackknife"`
  dispatch arm from `create_replicate_weights()`; DAGJK is now invoked via
  `method = "jackknife"` + `type = "grouped"`.
- Migrated all DAGJK tests from `test-nps-group-jackknife.R` to
  `test-nps-jackknife.R` using the new API; also updated all old type strings
  (`"delete-1"`, `"random-groups"`) in the broader replicate-weights test file.
- Added Tier 3 roxygen docs to `create_jackknife_weights()` including an
  Algorithm section covering JKn, JK1, grouped, and DAGJK; Convergence section;
  Limitations section; Warnings section; and full `@references`.
- 3568 tests pass, 0 failures; snapshot for `replicate-print.md` updated to
  reflect `type = "jkn"` (user-supplied string) stored in history rather than
  the backend string `"JKn"`.
