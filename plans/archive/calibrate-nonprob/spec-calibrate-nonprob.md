## Scope

### In

- `calibrate_to_survey()`: accept `survey_nonprob` objects with replicate weights
  as either `primary_design` or `control_design`.
- `calibrate_to_estimate()`: accept `survey_nonprob` objects with replicate weights
  as `design`.
- For `survey_nonprob` inputs, the output class is `survey_nonprob` (not
  `survey_replicate`).
- New error classes for `survey_nonprob` inputs that lack `@variables$repweights`.
- Updates to three existing `_not_replicate` error class condition descriptions in
  `plans/error-messages.md`.
- `@param` documentation updated for both functions to reflect the relaxed type
  constraint.
- `@return` documentation updated to document class-preservation rule.

### Out

- No change to `calibrate_to_survey()` or `calibrate_to_estimate()` behavior when
  both inputs are `survey_replicate` objects.
- No change to `survey_taylor` rejection (those errors remain unchanged).
- No change to any other function in the package.
- No new exported functions.
- No new statistical methods or algorithms.
- Snapshot updates for error classes whose message text is UNCHANGED are not in
  scope. The three `_not_replicate` error class snapshots WILL need updating in
  this PR because their message bodies change (the `"x"` bullet now names
  `survey_nonprob` as an additional accepted type).

## Function contracts

### `calibrate_to_survey(primary_design, control_design, variables, ...)`

#### Accepted input types

`primary_design` is accepted if it is:
- A `survey_replicate` object (existing behavior, unchanged), OR
- A `survey_nonprob` object with `@variables$repweights` non-NULL and
  `length(@variables$repweights) > 0`.

`control_design` is accepted if it is:
- A `survey_replicate` object (existing behavior, unchanged), OR
- A `survey_nonprob` object with `@variables$repweights` non-NULL and
  `length(@variables$repweights) > 0`.

Any other class for either argument is rejected with the appropriate
`_not_replicate` error (see Errors table below).

#### Return type rule

The output class matches the class of `primary_design`:
- `primary_design` is `survey_replicate` → returns `survey_replicate`
- `primary_design` is `survey_nonprob` → returns `survey_nonprob`

The class of `control_design` does NOT affect the output class. Any valid
combination of `primary_design` and `control_design` class is permitted.

#### Output construction

The builder must dispatch on the class of `primary_design` to select the
constructor:

- When `primary_design` is `survey_replicate`: call
  `surveycore::survey_replicate(data = new_data, variables = primary_design@variables, metadata = primary_design@metadata)`.
- When `primary_design` is `survey_nonprob`: call
  `surveycore::survey_nonprob(data = new_data, variables = primary_design@variables, metadata = primary_design@metadata)`.

In both cases, `new_data` is the updated data frame with the calibrated
full-sample and replicate weight columns written back. The `variables` and
`metadata` slots are carried forward from `primary_design` unchanged (except
that the weighting history entry is appended to `metadata`).

#### Validation order

The validation order for new checks relative to existing checks:

1. `primary_design` class check — fires before `control_design` check.
2. `control_design` class check.
3. All subsequent checks are unchanged from the current implementation.

The class-acceptability check for `survey_nonprob` is part of the same
validation step as the `survey_replicate` check, not an additional step after
it. The logic structure within step 1 is:

```
if primary_design is neither survey_replicate NOR survey_nonprob:
  error: surveywts_error_primary_not_replicate
else if primary_design is survey_nonprob AND repweights is NULL/empty:
  error: surveywts_error_primary_no_repweights
```

Step 2 follows the same structure for `control_design`.

#### Arguments

- **`primary_design`**: A `survey_replicate` or `survey_nonprob` (with replicate
  weights). The design to be calibrated. Must have replicate weights populated.
- **`control_design`**: A `survey_replicate` or `survey_nonprob` (with replicate
  weights). The reference survey from which population totals are estimated.
  Must have replicate weights populated. Does NOT affect output class.
- **`variables`**: `<tidy-select>` Bare names of calibration variables in
  `primary_design@data`. Behavior unchanged.
- **`method`**: One of `"rake"` (default), `"linear"`, `"logit"`. Behavior unchanged.
- **`bounds`**: Numeric vector of length 2. Behavior unchanged.
- **`unit_scale`**: `NULL` or positive numeric vector. Behavior unchanged.
- **`reference_design`**: A `survey_taylor` or `NULL`. Behavior unchanged.
- **`control`**: Named list. Behavior unchanged.

#### Returns

A calibrated design object. The class of the returned object matches the class
of `primary_design`:

- If `primary_design` is `survey_replicate`, returns a `survey_replicate` with
  updated full-sample and replicate weights.
- If `primary_design` is `survey_nonprob`, returns a `survey_nonprob` with
  updated full-sample and replicate weights.

In both cases, a history entry with `operation = "calibrate_to_survey"` is
appended to `@metadata@weighting_history`. The `control_design_class` field in
`history_params` records the actual class of `control_design` (unchanged from
current behavior).

#### Errors

| Class | Trigger condition |
|-------|-------------------|
| `surveywts_error_primary_not_replicate` | `primary_design` is not `survey_replicate` and not `survey_nonprob` (e.g., plain data.frame, `survey_taylor`, `weighted_df`) |
| `surveywts_error_primary_no_repweights` | `primary_design` is `survey_nonprob` but `@variables$repweights` is `NULL` or `length == 0` |
| `surveywts_error_control_not_replicate` | `control_design` is not `survey_replicate` and not `survey_nonprob` |
| `surveywts_error_control_no_repweights` | `control_design` is `survey_nonprob` but `@variables$repweights` is `NULL` or `length == 0` |
| `surveywts_error_reference_design_not_taylor` | `reference_design` is non-NULL and not `survey_taylor` — unchanged |
| `surveywts_error_unit_scale_invalid` | `unit_scale` fails validation — unchanged |
| `surveywts_error_variables_not_found` | Variable missing from `primary_design` or empty tidy-select — unchanged |
| `surveywts_error_calibration_not_converged` | svrep convergence failure — unchanged |
| `surveywts_error_calibration_failed` | svrep hard error — unchanged |

#### Error message format for new error classes

**`surveywts_error_primary_no_repweights`**:
```
"x" = "{.arg primary_design} is a {.cls survey_nonprob} but has no replicate weights."
"i" = "Replicate weights are required to propagate control-survey uncertainty."
"v" = "Use {.fn create_bootstrap_weights} or another {.fn create_*_weights}
       function to add replicate weights before calibrating."
```

**`surveywts_error_control_no_repweights`**:
```
"x" = "{.arg control_design} is a {.cls survey_nonprob} but has no replicate weights."
"i" = "Replicate weights are required to propagate control-survey uncertainty."
"v" = "Use {.fn create_bootstrap_weights} or another {.fn create_*_weights}
       function to add replicate weights."
```

The `_not_replicate` error messages must be updated so the informational bullet
reflects the expanded acceptance:
```
"x" = "{.arg primary_design} must be a {.cls survey_replicate} or a
       {.cls survey_nonprob} with replicate weights, got {.cls {cls}}."
"i" = "Replicate weights are required to propagate control-survey uncertainty."
"v" = "Use {.fn create_bootstrap_weights} or another {.fn create_*_weights}
       function to add replicate weights."
```
(Replace `primary_design` / `control_design` as appropriate.)

#### Warnings

All existing warnings are unchanged:
- `surveywts_warning_control_param_ignored`
- `surveywts_warning_replicate_scheme_mismatch`
- `surveywts_warning_negative_calibrated_weights`

#### Edge cases

| Case | Behavior |
|------|----------|
| `primary_design` is `survey_nonprob` with repweights, `control_design` is `survey_replicate` | Succeeds; returns `survey_nonprob` |
| `primary_design` is `survey_replicate`, `control_design` is `survey_nonprob` with repweights | Succeeds; returns `survey_replicate` |
| Both inputs are `survey_nonprob` with repweights | Succeeds; returns `survey_nonprob` |
| `primary_design` is `survey_nonprob` without repweights | Errors: `surveywts_error_primary_no_repweights` |
| `control_design` is `survey_nonprob` without repweights | Errors: `surveywts_error_control_no_repweights` |
| `primary_design` is a plain data.frame | Errors: `surveywts_error_primary_not_replicate` (unchanged) |
| `control_design` is a `survey_taylor` | Errors: `surveywts_error_control_not_replicate` (unchanged) |

### `calibrate_to_estimate(design, targets, vcov_estimate, ...)`

#### Accepted input types

`design` is accepted if it is:
- A `survey_replicate` object (existing behavior, unchanged), OR
- A `survey_nonprob` object with `@variables$repweights` non-NULL and
  `length(@variables$repweights) > 0`.

Any other class is rejected with `surveywts_error_design_not_replicate`.

#### Return type rule

The output class matches the class of `design`:
- `design` is `survey_replicate` → returns `survey_replicate`
- `design` is `survey_nonprob` → returns `survey_nonprob`

#### Output construction

The builder must dispatch on the class of `design` to select the constructor:

- When `design` is `survey_replicate`: call
  `surveycore::survey_replicate(data = new_data, variables = design@variables, metadata = design@metadata)`.
- When `design` is `survey_nonprob`: call
  `surveycore::survey_nonprob(data = new_data, variables = design@variables, metadata = design@metadata)`.

#### Validation order

The class check structure within step 1 is:

```
if design is neither survey_replicate NOR survey_nonprob:
  error: surveywts_error_design_not_replicate
else if design is survey_nonprob AND repweights is NULL/empty:
  error: surveywts_error_design_no_repweights
```

All subsequent validation steps (steps 2 through 11 in the current
implementation) are unchanged.

#### Arguments

- **`design`**: A `survey_replicate` or `survey_nonprob` (with replicate weights).
  The design to be calibrated. Must have replicate weights populated.
- All other arguments: unchanged from current contract.

#### Returns

A calibrated design object whose class matches the class of `design`:

- If `design` is `survey_replicate`, returns a `survey_replicate`.
- If `design` is `survey_nonprob`, returns a `survey_nonprob`.

A history entry with `operation = "calibrate_to_estimate"` is appended to
`@metadata@weighting_history`.

## Quality gates

- Output class always matches input class of the design being calibrated.
- `@variables$repweights` is preserved in the returned object (no trimming or
  renaming of replicate columns beyond what the existing implementation already
  does when `svrep` changes the count).
- `@metadata@weighting_history` grows by exactly one entry per call.
- The `control_design_class` field in `history_params` records `class(control_design)[[1L]]`
  (already present in existing implementation; no change required).
- All existing behavior for `survey_replicate` inputs is unchanged.
